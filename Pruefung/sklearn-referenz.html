StandardScaler

StandardScaler sklearn.preprocessing 
from sklearn.preprocessing import StandardScaler
X = np.array([[1, 200], [2, 300], [3, 400]])
scaler = StandardScaler()
StandardScaler(
    copy=True,      # Kopiert X statt es in-place zu überschreiben.
    with_mean=True, # Zentriert die Daten (subtrahiert den Mittelwert)
    with_std=True,  # Skaliert auf Einheitsvarianz (teilt durch die Standardabweichung).

📖 Parameter — Details
  • copy=True – Kopiert X statt es in-place zu überschreiben.
  • with_mean=True – Zentriert die Daten (subtrahiert den Mittelwert). Bei Sparse-Matrizen muss dies False sein.
  • with_std=True – Skaliert auf Einheitsvarianz (teilt durch die Standardabweichung).

OneHotEncoder sklearn.preprocessing 
from sklearn.preprocessing import OneHotEncoder
X_cat = [['rot'], ['gruen'], ['blau'], ['rot']]
OneHotEncoder(
    categories='auto',      # Kategorien automatisch aus Trainingsdaten
    drop=None,              # 'first' entfernt erste Kategorie (keine Multikollinearität)
    sparse_output=True,     # False → dichtes ndarray statt Sparse-Matrix
    handle_unknown='error', # 'ignore' → unbekannte Kategorien als 0-Vektor
    min_frequency=None,     # seltene Kategorien → gemeinsamer Bin

📖 Parameter — Details

  • min_frequency=None – Kategorien unter dieser Häufigkeit → ein gemeinsamer Seltene-Kategorie-Bin
  • max_categories=None – Begrenzt die maximale Anzahl an Output-Kategorien pro Feature

train_test_split

train_test_split sklearn.model_selection 
from sklearn.model_selection import train_test_split
X = np.arange(10).reshape(5, 2)
y = np.array([0, 1, 0, 1, 0])
train_test_split(
    *arrays,           # X, y, ..
    test_size=None,    # Anteil (float 0–1) oder Anzahl (int) der Testdaten
    train_size=None,   # Anteil/Anzahl Trainingsdaten
    random_state=None, # Seed für reproduzierbare Splits
    shuffle=True,      # mischt die Daten vor dem Split
    stratify=None,     # Array (meist y) für klassen-proportionalen Split
)
📖 Parameter — Details
  • *arrays – X, y, ... beliebig viele gleich lange Arrays/Matrizen, die synchron gesplittet werden.
  • test_size=None – Anteil (float 0–1) oder Anzahl (int) der Testdaten. Standard 0.25, wenn weder test_size noch train_size gesetzt sind.
  • train_size=None – Anteil/Anzahl Trainingsdaten — meist weggelassen, ergibt sich automatisch aus test_size.
  • random_state=None – Seed für reproduzierbare Splits — gleicher Wert = gleicher Split.
  • shuffle=True – mischt die Daten vor dem Split. Bei Zeitreihen auf False setzen, um die Reihenfolge zu erhalten.
  • stratify=None – Array (meist y) für klassen-proportionalen Split — wichtig bei unbalancierten Klassen.

test_size

Anteil für Test-Set, z.B. 0.4 = 40%

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.4, random_state=42)
train_shape = X_train.shape  # Zeilen × Features im Trainingsset
test_shape  = X_test.shape   # Zeilen × Features im Testset
print(train_shape, test_shape)
(3, 2) (2, 2)

random_state

Seed für Reproduzierbarkeit — gleicher Seed = gleicher Split

_, _, ytr1, _ = train_test_split(X, y, test_size=0.4, random_state=42)
_, _, ytr2, _ = train_test_split(X, y, test_size=0.4, random_state=42)
print(ytr1, ytr2)
[0 0 1] [0 0 1]

Standard True — bei Zeitreihen auf False setzen (Reihenfolge bleibt erhalten)

Ridge / Lasso sklearn.linear_model

Ridge

Ridge(
    alpha=1.0,          # Regularisierungsstärke (L2)
    fit_intercept=True, # Achsenabschnitt mitschätzen.
    copy_X=True,        # kopiert X statt es in-place zu überschreiben.
    max_iter=None,      # max

📖 Parameter — Details

  • fit_intercept=True – Achsenabschnitt mitschätzen.
  • copy_X=True – kopiert X statt es in-place zu überschreiben.
  • max_iter=None – max. Iterationen für iterative Solver; None = solverabhängiger Default.
  • tol=1e-4 – Konvergenztoleranz für iterative Solver.
  • solver='auto' – wählt automatisch passenden Solver ('svd', 'cholesky', 'lsqr', 'sag', 'saga', ...).
  • positive=False – erzwingt nicht-negative Koeffizienten.
  • random_state=None – nur relevant für die Solver 'sag'/'saga'.

Lasso

Lasso(
    alpha=1.0,          # Regularisierungsstärke (L1)
    fit_intercept=True, # Achsenabschnitt mitschätzen.

)
📖 Parameter — Details
  • alpha=1.0 – Regularisierungsstärke (L1) — größer = mehr Koeffizienten werden exakt 0 (automatische Feature-Selektion).
  • fit_intercept=True – Achsenabschnitt mitschätzen.
  • copy_X=True – kopiert X statt es in-place zu überschreiben.
  • max_iter=1000 – max. Iterationen des Koordinatenabstiegs — bei Konvergenzwarnung erhöhen.
  • tol=1e-4 – Konvergenztoleranz.
  • selection='cyclic' – 'random' wählt die zu aktualisierende Koordinate zufällig — kann bei hochdimensionalen Daten schneller konvergieren.
  • positive=False – erzwingt nicht-negative Koeffizienten.
  • random_state=None – relevant bei selection='random'.

Support Vector Machine (SVC) sklearn.svm 
from sklearn.svm import SVC
X = [[0, 0], [1, 1], [1, 0], [0, 1]]   # XOR-Muster

SVC(
    C=1.0,                         # Soft-Margin-Strafterm
    kernel='rbf',                  # Kernel-Funktion
    degree=3,                      # Polynomgrad, nur relevant für kernel='poly'.
    gamma='scale',                 # Kernel-Koeffizient für 'rbf'/'poly'/'sigmoid'
    coef0=0.0,                     # unabhängiger Term, nur für 'poly'/'sigmoid'.
    shrinking=True,                # nutzt eine Shrinking-Heuristik für schnelleres Training.
    probability=False,             # aktiviert predict_proba() über interne Kreuzvalidierung
    tol=1e-3,                      # Konvergenztoleranz.
    class_weight=None,             # 'balanced' für unbalancierte Klassen.
    max_iter=-1,                   # -1 = kein Limit der Solver-Iterationen.
    decision_function_shape='ovr', # 'ovr' (One-vs-Rest) oder 'ovo' (One-vs-One) für Mehrklassen-Probleme.
    random_state=None,             # Seed für interne Datenmischung bei probability=True.
)
📖 Parameter — Details
  • C=1.0 – Soft-Margin-Strafterm — kleiner = breitere Margin, mehr Toleranz für Fehlklassifikationen; größer = engere Margin, Risiko von Overfitting.
  • kernel='rbf' – Kernel-Funktion — 'linear', 'poly', 'rbf' oder 'sigmoid'.
  • degree=3 – Polynomgrad, nur relevant für kernel='poly'.
  • gamma='scale' – Kernel-Koeffizient für 'rbf'/'poly'/'sigmoid' — größer = komplexere, engere Entscheidungsgrenze.
  • coef0=0.0 – unabhängiger Term, nur für 'poly'/'sigmoid'.
  • shrinking=True – nutzt eine Shrinking-Heuristik für schnelleres Training.
  • probability=False – aktiviert predict_proba() über interne Kreuzvalidierung — verlangsamt das Training deutlich.
  • tol=1e-3 – Konvergenztoleranz.
  • class_weight=None – 'balanced' für unbalancierte Klassen.
  • max_iter=-1 – -1 = kein Limit der Solver-Iterationen.
  • decision_function_shape='ovr' – 'ovr' (One-vs-Rest) oder 'ovo' (One-vs-One) für Mehrklassen-Probleme.
  • random_state=None – Seed für interne Datenmischung bei probability=True.

DecisionTreeClassifier / Regressor

DecisionTreeClassifier / Regressor sklearn.tree 
from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import load_iris
X, y = load_iris(return_X_y=True)
DecisionTreeClassifier(
    criterion='gini',             # Splitkriterium
    splitter='best',              # 'best' wählt den besten Split, 'random' den besten unter zufälligen…
    max_depth=None,               # maximale Baumtiefe
    min_samples_split=2,          # Mindestanzahl Samples, damit ein Knoten weiter gesplittet wird.
    min_samples_leaf=1,           # Mindestanzahl Samples pro Blatt
    min_weight_fraction_leaf=0.0, # wie min_samples_leaf, aber als Anteil der gewichteten Gesamtsumme…
    max_features=None,            # Anzahl/Anteil Features, die pro Split betrachtet werden ('sqrt',…
    max_leaf_nodes=None,          # Begrenzung der maximalen Blattanzahl.
    min_impurity_decrease=0.0,    # Mindest-Verbesserung der Unreinheit, damit ein Split durchgeführt…
    class_weight=None,            # 'balanced' für unbalancierte Klassen.
    ccp_alpha=0.0,                # Komplexitätsparameter für Cost-Complexity-Pruning
    random_state=None,            # Seed für splitter='random' bzw. zufällige Feature-Auswahl.
)
📖 Parameter — Details
  • criterion='gini' – Splitkriterium — 'gini', 'entropy' oder 'log_loss'.
  • splitter='best' – 'best' wählt den besten Split, 'random' den besten unter zufälligen Kandidaten (mehr Varianz, schneller).
  • max_depth=None – maximale Baumtiefe — None = bis alle Blätter rein sind (hohes Overfitting-Risiko).
