1 Data Preparation

train_test_split → Thema

n_test = int(N × test_size)
stratify=y → Klassenverteilung in Train & Test erhalten

Normalisierung → Thema

Min-Max:  x' = (x − x_min) / (x_max − x_min)  → [0,1]
Z-Score:  x' = (x − μ) / σ  → μ≈0, σ≈1
⚠️ Scaler nur auf X_train fitten, dann transform() auf X_train & X_test anwenden — niemals fit_transform auf Testdaten!

Encoding → Thema

MethodeFürBeispiel
Label-Encodingnur Ziel yA→0, B→1, C→2
Ordinal-Encodingordinale Features Xklein→0, mittel→1, groß→2
One-Hot-Encodingnominale Features Xrot=[1,0,0], blau=[0,1,0]
Dummy-Variable-Trap: bei K Kategorien nur K−1 Spalten nötig → drop='first'

Feature Scaling → Thema

RobustScaler:  x' = (x − Median) / IQR  (IQR = Q3−Q1)
Log:  x' = log(x + 1)  (rechtsschiefe Daten)
Box-Cox:  x' = (x^λ − 1)/λ  (nur x>0)  ·  Yeo-Johnson: alle x
✅ Scaling nötig: k-NN, SVM, Log. Regression, NN, PCA, k-Means
❌ Nicht nötig: Entscheidungsbäume, Random Forest, Gradient Boosting

Feature Selection → Thema

VarianceThreshold:  Var(Xⱼ) = (1/N) Σ(xᵢ − μⱼ)²
ANOVA F-Wert:  F = (SSB/(K−1)) / (SSW/(N−K))
Filter (VarianceThreshold, SelectKBest) · Wrapper (RFE) · Embedded (Lasso/L1, Feature Importance)
Fluch der Dimensionalität: bei d=100 sind alle Punkte fast gleich weit entfernt (d_min ≈ 0.98).

2 ML Grundlagen

Was ist ML? → Thema

Supervised (gelabelte Daten) · Unsupervised (keine Labels) · Reinforcement (Belohnung)
MSE = (1/n) · Σ (y_pred − y_true)²

Overfitting & Underfitting → Thema

SymptomDiagnoseLösung
Train ≈ Test (beide niedrig)Underfitting / High BiasKomplexeres Modell, mehr Features, weniger Regularisierung
Train hoch, Test niedrigOverfitting / High VarianceRegularisierung, mehr Daten, Ensemble
Ridge (L2):  Loss = MSE + α·Σwⱼ²
Lasso (L1):  Loss = MSE + α·Σ|wⱼ|
L2 (Ridge): straft Gewichte² → schrumpft alle Gewichte gleichmäßig · L1 (Lasso): straft |Gewichte| → setzt viele Gewichte exakt auf 0 (Feature Selection) · Bei Bäumen: max_depth, min_samples_leaf

Bias-Variance Tradeoff → Thema

E[(y − ŷ)²] = Bias² + Variance + Irreducible Noise
KomponenteBedeutungReduzierbar?
Bias²Modell zu simpel (systematischer Fehler)Ja – komplexeres Modell
VarianceSensitivität ggü. TrainingsdatenJa – Regularisierung, mehr Daten
NoiseZufälliges RauschenNein

Cross-Validation → Thema

CV-Score = μ(Score₁..Scoreₖ), CV-Std = σ(Score₁..Scoreₖ)
K-Fold (Standard, k=5/10) · Stratified K-Fold (Klassifikation) · LOOCV (n Folds) · Repeated K-Fold · TimeSeriesSplit (Zeitreihen)
Nested CV: äußere Loop = Performance schätzen, innere Loop (GridSearchCV) = Hyperparameter tunen.

3 Support Vector Machines

Hyperebene & Margin → Thema

Hyperebene:  wᵀx + b = 0
Margin-Breite:  2 / ‖w‖  → maximieren = ‖w‖ minimieren
Hard-Margin:  min ½‖w‖²  unter  yᵢ(wᵀxᵢ+b) ≥ 1
Decision Function:  f(x) = sign(Σ αᵢ yᵢ ⟨xᵢ,x⟩ + b)
Support Vectors: Punkte mit αᵢ>0, liegen auf dem Margin-Rand — nur sie bestimmen die Hyperebene.

Soft Margin & C → Thema

min ½‖w‖² + C·Σξᵢ  unter  yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ, ξᵢ≥0
Hinge Loss:  L = max(0, 1 − yᵢ(wᵀxᵢ+b))
CEffektBias/Variance
klein (0.01)viele Fehler erlaubt, breiter MarginHigh Bias
groß (1000)wenige Fehler, schmaler MarginHigh Variance

Kernel-Trick → Thema

K(xᵢ,xⱼ) = ⟨φ(xᵢ), φ(xⱼ)⟩
KernelFormelParameter
LinearK(x,z) = xᵀz—
PolynomialK(x,z) = (γxᵀz + r)ᵈdegree, gamma, coef0
RBF/GaußK(x,z) = exp(−γ‖x−z‖²)gamma
SigmoidK(x,z) = tanh(γxᵀz + r)gamma, coef0
γ klein → glatte Grenze (Underfitting) · γ groß → komplexe Grenze (Overfitting)

SVC mit sklearn → Thema

f(x) = sign(Σᵢ αᵢ·yᵢ·K(xᵢ,x) + b)

4 Clustering & PCA

k-Means Algorithmus → Thema

Inertia (WCSS):  Σₖ Σᵢ∈Cₖ ‖xᵢ − μₖ‖²
Assignment:  cᵢ = argminₖ ‖xᵢ − μₖ‖²
Update:  μₖ = (1/|Cₖ|) · Σᵢ∈Cₖ xᵢ
Lloyd's Algorithmus: 1) Centroids initialisieren (k-means++) → 2) Assignment → 3) Update → 4) wiederholen bis Konvergenz.
Voraussetzung: sphärische Cluster · Zeitkomplexität O(n·k·t·d)

Elbow-Methode → Thema

Inertia(k) plotten → "Ellbogen" (stärkster Knick) = optimales k.
Silhouette: s(i) = (b(i)−a(i)) / max(a(i),b(i))  ∈ [-1,1], höher = besser
Davies-Bouldin: Ø Verhältnis (Intra-Cluster-Streuung) / (Inter-Cluster-Distanz), niedriger = besser
Dunn-Index: D = min(Inter-Cluster-Distanz) / max(Intra-Cluster-Distanz), höher = besser
Alle drei sind interne Validierungsmaße (ohne Ground-Truth-Labels). sklearn: silhouette_score, davies_bouldin_score — Dunn-Index ist nicht in sklearn enthalten, muss ggf. selbst implementiert werden.

DBSCAN → Thema

Parameter: eps (Radius), min_samples (Mindestpunkte)
Core: ≥min_samples im eps-Radius · Border: im eps-Radius eines Core-Punkts · Noise: weder noch.
Vorteile: kein k nötig, beliebige Cluster-Formen, erkennt Ausreißer automatisch.
Algorithmusk vorgeben?wann nutzen
AgglomerativeClusteringJa (oder Dendrogramm)Hierarchie gewünscht
SpectralClusteringJanicht-konvexe Cluster (Monde, Ringe)
MeanShiftNein (bandwidth)k unbekannt, dichte-basiert
OPTICSNeinvariable Dichte
BirchOptionalsehr große Datenmengen
KMedoids (k-Median)Jarobust gg. Ausreißer (Medoid statt Mittelwert)

KMeans mit sklearn → Thema

k-means++ Init: erster Centroid zufällig, jeder weitere proportional zu Abstand² vom nächsten bestehenden Centroid — verhindert Zusammenfallen.

PCA & Dimensionsreduktion → Thema

Kovarianzmatrix:  Σ = (1/(n−1)) · Xᶜᵀ · Xᶜ
Eigenzerlegung:  Σ · v = λ · v  (v = Hauptkomponente, λ = erklärte Varianz)
Erklärte Varianz (Anteil)ᵢ:  λᵢ / Σⱼ λⱼ
PCA ist unüberwacht und varianz-basiert → immer StandardScaler vorher anwenden. Scree-Plot: erklärte Varianz pro Komponente absteigend auftragen — der "Ellbogen" zeigt ein sinnvolles k (analog zur Elbow-Methode).

5 Tree-Based Models

Entscheidungsbaum → Thema

Entropie:  H(S) = − Σ pᵢ · log₂(pᵢ)
Gini:  G(S) = 1 − Σ pᵢ²  (binär: 2·p·(1−p))
Information Gain:  IG = H(parent) − Σ (|Sₗ|/|S|·H(Sₗ) + |Sᵣ|/|S|·H(Sᵣ))
Gini=0 → reine Klasse · Gini=0.5 → 50/50. Stopping: max_depth, min_samples_split, min_samples_leaf.

Bagging → Thema

σ²_bag = σ²/B  (unkorreliert)
σ²_bag = σ²·(ρ + (1−ρ)/B)  (mit Korrelation ρ)
Für b=1..B: Bootstrap-Stichprobe ziehen → Modell trainieren → Vorhersagen mitteln (bzw. Mehrheitsvotum).

Random Forest → Thema

Zusätzlich zu Bagging: pro Split nur m = √d zufällige Features → reduziert Korrelation zwischen Bäumen, stärkere Varianzreduktion.
OOB-Error: jeder Baum sieht ~63.2% der Daten, die übrigen ~36.8% (OOB) dienen zur Evaluation ohne Test-Set.
HyperparameterBedeutungTuning-Effekt
n_estimatorsAnzahl Bäume↑ stabiler, aber langsamer — kaum Overfitting-Risiko
max_depthMax. Tiefe pro Baum↓ reduziert Overfitting
max_featuresFeatures pro Split (m)↓ mehr Diversität, weniger Korrelation
min_samples_leafMin. Samples pro Blatt↑ glattere Entscheidungsgrenzen

Feature Importance → Thema

Gini-Importance: Σ (Anteil Samples am Split) × (Impurity-Reduktion)
Permutation Importance: Feature zufällig permutieren → Fehleranstieg = Importance

Boosting & Regression-Bäume → Thema

AdaBoost: εₘ = Σᵢ wᵢ·𝟙(yᵢ≠ŷᵢ) / Σᵢ wᵢ  →  αₘ = ln((1−εₘ)/εₘ)
Gradient Boosting: F₀ = ȳ  →  rᵢ = yᵢ − Fₘ₋₁(xᵢ)  →  Fₘ = Fₘ₋₁ + ν·hₘ(x)
Bagging/RF: parallel, tiefe Bäume, reduziert Variance. Boosting: sequentiell, flache Bäume (max_depth 1-5, "weak learners"), reduziert Bias. learning_rate (ν) ↓ + n_estimators ↑ = Shrinkage. staged_predict() für Learning-Curve/Early-Stopping. Regression-Baum: criterion='squared_error', Blatt sagt Mittelwert voraus.

6 Gaussian Mixture Models

Gaußverteilung → Thema

Univariat:  p(x|μ,σ²) = 1/√(2πσ²) · exp(−(x−μ)²/(2σ²))
Multivariat:  p(x|μ,Σ) = 1/√((2π)ᵏ|Σ|) · exp(−½(x−μ)ᵀΣ⁻¹(x−μ))

EM-Algorithmus → Thema

E-Schritt: Responsibilities berechnen — wie wahrscheinlich gehört Punkt i zu Komponente k?
M-Schritt: Parameter (π, μ, Σ) basierend auf Responsibilities aktualisieren.
Wiederholen bis Konvergenz — Log-Likelihood steigt monoton (ggf. lokales Maximum).

E-Step & M-Step → Thema

E-Step:  rᵢₖ = πₖ·N(xᵢ|μₖ,Σₖ) / Σⱼ πⱼ·N(xᵢ|μⱼ,Σⱼ)  (Σₖ rᵢₖ = 1)

M-Step:  Nₖ = Σᵢ rᵢₖ
  πₖ = Nₖ/N
  μₖ = (1/Nₖ)·Σᵢ rᵢₖ·xᵢ
  Σₖ = (1/Nₖ)·Σᵢ rᵢₖ·(xᵢ−μₖ)(xᵢ−μₖ)ᵀ
Soft Clustering: jeder Punkt hat eine Wahrscheinlichkeit pro Komponente (statt harter Zuweisung wie bei k-means).

GaussianMixture mit sklearn → Thema

covariance_type: 'full' · 'tied' · 'diag' · 'spherical'
BIC/AIC: kleiner = besser (Modellwahl) · Log-Likelihood: höher = besser
score(X) → log p(X) für Density Estimation.

7 Evaluation

Confusion Matrix → Thema

Accuracy = (TP+TN)/(TP+TN+FP+FN)
Precision = TP/(TP+FP)  ·  Recall = TP/(TP+FN)  ·  Specificity = TN/(TN+FP)
F1 = 2·(P·R)/(P+R)  ·  F_β = (1+β²)·P·R / (β²·P+R)
Eselsbrücke: Precision = "Wenn ich Alarm schlage, habe ich recht" (FP vermeiden) · Recall = "Wenn Gefahr da ist, erkenne ich sie" (FN vermeiden).
Multiklass-Averaging: Macro = ungewichteter Mittelwert über alle Klassen (jede Klasse zählt gleich) · Weighted = nach Klassenhäufigkeit gewichtet · Micro = global über alle TP/FP/FN gepoolt (= Accuracy bei Single-Label).

ROC & AUC → Thema

FPR = FP/(FP+TN)  (x-Achse)  ·  TPR = Recall = TP/(TP+FN)  (y-Achse)
AUC = 1.0 perfekt · AUC = 0.5 zufällig · AUC < 0.5 schlechter als Zufall
AUC = Wahrscheinlichkeit, dass ein zufälliger positiver Punkt höher bewertet wird als ein zufälliger negativer.
Multi-Class: roc_auc_score(y_true, y_proba, multi_class='ovr'|'ovo', average='macro'|'weighted') — y_proba = volle predict_proba()-Matrix (eine Spalte pro Klasse). OvR: k Kurven ("Klasse vs. Rest"). OvO: k·(k−1)/2 Kurven (Klassenpaare).

Precision-Recall-Tradeoff → Thema

High Precision wichtig: FP teuer (z.B. Spam-Filter)
High Recall wichtig: FN teuer (z.B. Krankheitserkennung)
PR-Kurve: Recall (x) vs. Precision (y) — mehr Recall → meist weniger Precision.

CV & Fehleranalyse → Thema

CV Score = μ ± σ  ·  Konfidenzintervall ≈ μ ± 2σ/√K
Bootstrap-CI: Resampling mit Zurücklegen → [2.5%, 97.5%]-Perzentil = 95%-CI
Data Leakage: Scaler/Feature Selection auf gesamtem Datensatz fitten, Hyperparameter-Tuning auf Test-Set, mehrfache Test-Set-Evaluation.
Nested CV: äußere Schleife = Performance schätzen, innere Schleife (GridSearchCV) = Hyperparameter tunen. Learning Curves: Lücke Train/Val groß → Overfitting; beide niedrig → Underfitting.
