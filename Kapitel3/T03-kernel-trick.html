🌀 Der Kernel-Trick

Wie kann eine SVM nichtlineare Entscheidungsgrenzen finden — ohne die Daten explizit in höhere Dimensionen zu transformieren?

Stufe 1

🎯 Ziel & Kontext

Das XOR-Problem: Nicht linear trennbar

Manche Datensätze sind in 2D nicht linear trennbar:

x₁=0, x₂=0 → Klasse −1 (○)
x₁=0, x₂=1 → Klasse +1 (×)
x₁=1, x₂=0 → Klasse +1 (×)
x₁=1, x₂=1 → Klasse −1 (○)
→ Keine Gerade kann ○ von × trennen!

Idee: Transformiere die Daten in eine höhere Dimension, wo sie linear trennbar sind. Das ist der Feature-Map-Ansatz.

Problem: Explizite Transformation in sehr hohe Dimensionen (z.B. Polynome Grad 10 mit 100 Features → tausende Features) ist rechentechnisch teuer.
Lösung: Kernel-Trick — berechne das Skalarprodukt im höherdimensionalen Raum, ohne die Transformation explizit durchzuführen!
Stufe 2

🧠 Was ist ein Kernel?

Die Kernidee

In der dualen SVM-Formulierung brauchen wir nur Skalarprodukte ⟨xᵢ, xⱼ⟩ — nie die einzelnen Koordinaten. Ein Kernel ist eine Funktion:

K(xᵢ, xⱼ) = ⟨φ(xᵢ), φ(xⱼ)⟩

wobei φ die Feature-Map ist. Der Kernel berechnet das Skalarprodukt implizit im höherdimensionalen Raum, ohne φ(x) explizit auszurechnen.

Die wichtigsten Kernels

KernelFormelParameterWann nutzen
Linear K(x,z) = xᵀz — Hoch-dimensionale Daten, Text, lineare Trennbarkeit
Polynomial K(x,z) = (γxᵀz + r)ᵈ degree, gamma, coef0 Polynomiale Beziehungen
RBF / Gauß K(x,z) = exp(−γ||x-z||²) gamma Standard-Choice, nichtlinear, unbekannte Struktur
Sigmoid K(x,z) = tanh(γxᵀz + r) gamma, coef0 Neural-Network-ähnlich

Der RBF-Kernel im Detail

K(x,z) = exp(−γ||x−z||²) — γ steuert wie schnell der Einfluss eines Support Vectors abfällt:

γ-WertEffektModell
Kleines γ (0.001)Weite Gaussian-Glocke → jeder SV hat großen EinflussGlattere Entscheidungsgrenze → Underfitting
Mittleres γ ('scale')Ausgewogener EinflussbereichGood Fit
Großes γ (100)Enge Gaussian-Glocke → nur nahe Punkte beeinflussenKomplexe, gezackte Grenze → Overfitting
gamma='scale' (Standard in sklearn): γ = 1/(n_features · X.var()) — automatisch skaliert.
gamma='auto': γ = 1/n_features — ältere Default.
Stufe 3

⚙️ Kernel-SVM Vorhersage

Die Vorhersage für einen neuen Punkt x basiert auf den Support Vectors:

f(x) = sign(Σᵢ αᵢ · yᵢ · K(xᵢ, x) + b)
1
Kernel zwischen Testpunkt x und jedem Support Vector xᵢ berechnen

K(xᵢ, x) = exp(−γ||xᵢ − x||²) für RBF

2
Gewichtete Summe der Kernel-Werte

Jeder Support Vector steuert mit Gewicht αᵢ · yᵢ bei.

3
Vorzeichen → Klasse

f(x) > 0 → Klasse +1, f(x) < 0 → Klasse −1

Beachte: Nie die Transformation φ(x) berechnen — nur die Kernel-Funktion K(xᵢ, x). Das ist der "Trick".
Stufe 4

🛠️ Von Scratch: RBF-Kernel Vorhersage

🐍 4/5a — Funktionen: Kernel-Funktionen & Kernel-Matrix 
import numpy as np

# Kernel-Funktionen von Scratch
def linear_kernel(x1, x2):
    return np.dot(x1, x2)

def polynomial_kernel(x1, x2, degree=3, gamma=1.0, coef0=0.0):
    return (gamma * np.dot(x1, x2) + coef0) ** degree

def rbf_kernel(x1, x2, gamma=1.0):
    diff = x1 - x2
    return np.exp(-gamma * np.dot(diff, diff))

def sigmoid_kernel(x1, x2, gamma=1.0, coef0=0.0):
    return np.tanh(gamma * np.dot(x1, x2) + coef0)


# Kernel-Matrix (Gram-Matrix) berechnen
def kernel_matrix(X1, X2, kernel_fn, **kwargs):
    """K[i,j] = kernel(X1[i], X2[j])"""
    n1, n2 = len(X1), len(X2)
    K = np.zeros((n1, n2))
    for i in range(n1):
        for j in range(n2):
            K[i, j] = kernel_fn(X1[i], X2[j], **kwargs)
    return K

Test: Kernel-Trick für das XOR-Problem — mit RBF-Kernel und sklearn-Verifikation:

🐍 4/5b — Test: RBF-Kernel-Matrix für XOR 
from sklearn.svm import SVC

X_xor = np.array([[0,0], [0,1], [1,0], [1,1]], dtype=float)
y_xor = np.array([-1, 1, 1, -1])

# In 2D nicht linear trennbar — RBF-Kernel macht es lösbar
K = kernel_matrix(X_xor, X_xor, rbf_kernel, gamma=1.0)
print("RBF Kernel-Matrix für XOR:")
print(np.round(K, 3))
# Ähnliche Klassen haben hohe Kernel-Werte
# K[0,3] (beide −1) sollte > K[0,1] (verschiedene Klassen) sein

# Verifiziere mit sklearn
svm = SVC(
    kernel='rbf',
    gamma=1.0,
    C=10
)
svm.fit(X_xor, y_xor)
print(f"\nXOR Predictions: {svm.predict(X_xor)}")
print(f"Expected:        {y_xor}")
print(f"Korrekt: {np.all(svm.predict(X_xor) == y_xor)}")

📊 Visualisierung — Kernel-Trick: 2D → höherdimensional

Beim XOR-Problem liegen die Punkte (0,0) und (1,1) (Klasse −1) sowie (0,1) und (1,0) (Klasse +1) so, dass keine Gerade sie trennt (links). Die Feature-Map φ(x₁,x₂) = (x₁, x₂, x₁·x₂) hebt die Punkte in eine dritte Dimension (rechts) — dort trennt eine flache Ebene die beiden Klassen perfekt. Der RBF-Kernel macht etwas Ähnliches implizit: Die Kernel-Matrix oben zeigt, dass Punkte derselben Klasse (z.B. (0,0) und (1,1), K=0.135) einen anderen "Ähnlichkeitswert" haben als Punkte verschiedener Klassen — genug, damit die SVM eine trennende Hyperebene im (impliziten) höherdimensionalen Raum findet.

Jetzt rekonstruieren wir die SVM-Vorhersage manuell mit den von sklearn gelernten Gewichten — das macht sichtbar, wie f(x) = sign(Σ αᵢyᵢ·K(SVᵢ,x) + b) konkret berechnet wird:

🐍 5/5a — Klasse: KernelSVMPredictor 
class KernelSVMPredictor:
    """
    Rekonstruiert SVM-Vorhersage von Scratch mit sklearn-Gewichten.
    Zeigt wie die Vorhersage intern funktioniert.
    """

    def __init__(self, svm_model):
        self.alphas = svm_model.dual_coef_[0]      # αᵢ · yᵢ
        self.svs    = svm_model.support_vectors_    # Support Vectors
        self.b      = svm_model.intercept_[0]
        self.gamma  = svm_model._gamma

    def predict_manual(self, x):
        """f(x) = sign(Σ αᵢyᵢ · K(SVᵢ, x) + b)"""
        kernel_vals = np.array([
            rbf_kernel(sv, x, gamma=self.gamma)
            for sv in self.svs
        ])
        decision = np.dot(self.alphas, kernel_vals) + self.b
        return int(np.sign(decision))
🐍 5/5b — Test: KernelSVMPredictor vs. sklearn 
from sklearn.datasets import make_moons
from sklearn.preprocessing import StandardScaler

X, y = make_moons(
    n_samples=100,
    noise=0.2,
    random_state=42
)
y_svm = np.where(y == 0, -1, 1)
Xs = StandardScaler().fit_transform(X)

svm = SVC(
    kernel='rbf',
    C=1.0,
    gamma=1.0
)
svm.fit(Xs, y_svm)

predictor = KernelSVMPredictor(svm)
# Vergleiche sklearn vs. manuelle Vorhersage
matches = sum(
    predictor.predict_manual(Xs[i]) == svm.predict([Xs[i]])[0]
    for i in range(20)
)
print(f"Übereinstimmung (erste 20): {matches}/20")

🐍 Schritt 1 — Kernel-Vergleich auf drei Datensätzen 
from sklearn.svm import SVC
from sklearn.datasets import make_moons, make_circles, make_classification
from sklearn.model_selection import cross_val_score
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
import numpy as np

# Drei verschiedene Datensätze
datasets = {
    'Moons (nichtlinear)':   make_moons(n_samples=200, noise=0.2, random_state=42),
    'Circles (nichtlinear)': make_circles(n_samples=200, noise=0.1, random_state=42),
    'Linear separierbar':    make_classification(
        n_samples=200,
        n_features=2,
        n_redundant=0,
        class_sep=2.0,
        random_state=42
    ),
}

kernels = ['linear', 'poly', 'rbf', 'sigmoid']

for ds_name, (X, y) in datasets.items():
    print(f"\n=== {ds_name} ===")
    print(f"{'Kernel':<12} | {'CV Acc':>8} | {'Std':>6}")
    print("-" * 35)
    for k in kernels:
        pipe = Pipeline([
            ('scaler', StandardScaler()),
            ('svm',    SVC(kernel=k, C=1.0, gamma='scale'))
        ])
        scores = cross_val_score(pipe, X, y, cv=5, scoring='accuracy')
        print(f"{k:<12} | {scores.mean():>8.2%} | {scores.std():>6.4f}")

Anschließend eine Grid-Search über C und gamma für den RBF-Kernel auf einem realen Datensatz:

🐍 Schritt 2 — Grid-Search für RBF: C & gamma 
from sklearn.model_selection import GridSearchCV
from sklearn.datasets import load_breast_cancer

X, y = load_breast_cancer(return_X_y=True)
pipe = Pipeline([
    ('sc', StandardScaler()),
    ('svm', SVC(kernel='rbf'))
])
param_grid = {
    'svm__C':     [0.1, 1, 10, 100],
    'svm__gamma': [0.001, 0.01, 0.1, 'scale'],
}
gs = GridSearchCV(
    pipe,
    param_grid,
    cv=5,
    scoring='accuracy',
    n_jobs=-1
)
gs.fit(X, y)
print(f"Breast Cancer — Beste Parameter: {gs.best_params_}")
print(f"Beste CV Accuracy: {gs.best_score_:.4f}")
