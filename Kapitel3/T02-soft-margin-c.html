🔧 Soft Margin & C

Was passiert wenn Daten nicht linear trennbar sind? Wie erlaubt man dem SVM-Modell Fehler — kontrolliert durch den Parameter C?

Stufe 1

🎯 Ziel & Kontext

Das Problem der Hard-Margin SVM

Die Hard-Margin SVM funktioniert nur für perfekt linear trennbare Daten. Aber reale Daten haben fast immer:

  • Ausreißer — einzelne falsch platzierte Punkte
  • Überlappende Klassen — keine perfekte Trennlinie existiert
  • Rauschen — zufällige Fehlmessungen
Lösung: Soft-Margin SVM — erlaube einige Fehler (Margin-Verletzungen), aber bestrafe sie mit dem Parameter C.
Stufe 2

🧠 Slack-Variablen und der C-Parameter

Slack-Variablen ξᵢ

Für jeden Punkt wird eine Slack-Variable ξᵢ ≥ 0 eingeführt:

ξᵢ = 0 → Punkt korrekt, außerhalb Margin
0 < ξᵢ ≤ 1 → Punkt korrekt, aber INNERHALB Margin
ξᵢ > 1 → Punkt FALSCH klassifiziert

Das Soft-Margin Optimierungsproblem

Minimiere: ½ · ||w||² + C · Σ ξᵢ
unter: yᵢ · (wᵀxᵢ + b) ≥ 1 − ξᵢ
und: ξᵢ ≥ 0 für alle i

Was C steuert

C = 0.01

Kleines C
Viele Fehler erlaubt → Breiter Margin → High Bias, Low Variance → Underfitting möglich

C = 1.0

Mittleres C
Balance zwischen Margin-Breite und Fehlerstrafe → guter Startpunkt

C = 1000

Großes C
Wenige Fehler erlaubt → Schmaler Margin → Low Bias, High Variance → Overfitting möglich

C als Bias-Variance Regler

C-WertMarginFehlertoleranzModellkomplexität
Klein (0.001)BreitHochNiedrig → Underfitting
Mittel (1.0)MediumMediumAusgewogen
Groß (1000)SchmalNiedrigHoch → Overfitting
Wichtig: C in sklearn ist der Kehrwert der Regularisierungsstärke. C=0.01 bedeutet starke Regularisierung (wie alpha=100 bei Ridge). Je kleiner C, desto mehr Regularisierung.
Stufe 3

⚙️ Hinge Loss — die Verlustfunktion der SVM

Das Soft-Margin-Problem kann als Verlustfunktions-Minimierung umgeschrieben werden:

Hinge Loss: L(yᵢ, ŷᵢ) = max(0, 1 − yᵢ · (wᵀxᵢ + b))

Gesamtverlust: (1/C) · ½||w||² + Σ max(0, 1 − yᵢfᵢ)
1
Korrekt & außerhalb Margin: fᵢ ≥ 1

max(0, 1-1) = 0 → kein Verlust

2
Korrekt aber im Margin: 0 < fᵢ < 1

max(0, 1-0.7) = 0.3 → kleiner Verlust

3
Falsch klassifiziert: fᵢ < 0

max(0, 1-(-0.5)) = 1.5 → großer Verlust

Stufe 4

🛠️ Von Scratch: Soft-Margin SVM mit Hinge Loss

🐍 4/5a — Klasse: SoftMarginSVM 
import numpy as np

class SoftMarginSVM:
    """
    Soft-Margin SVM via Subgradient Descent mit Hinge Loss.
    Primal-Form: min ½||w||² + C·Σmax(0, 1 - yᵢ(wᵀxᵢ+b))
    """

    def __init__(self, C=1.0, lr=0.001, n_iter=1000):
        self.C = C
        self.lr = lr
        self.n_iter = n_iter

    def fit(self, X, y):
        y_ = np.where(y <= 0, -1, 1)
        n, d = X.shape
        self.w = np.zeros(d)
        self.b = 0.0
        self.losses = []

        for epoch in range(self.n_iter):
            total_loss = 0
            for i in range(n):
                margin = y_[i] * (np.dot(self.w, X[i]) + self.b)
                hinge  = max(0, 1 - margin)
                total_loss += 0.5 * np.dot(self.w, self.w) + self.C * hinge

                if hinge > 0:
                    # Subgradient bei Verletzung
                    self.w = self.w - self.lr * (self.w - self.C * y_[i] * X[i])
                    self.b = self.b + self.lr * self.C * y_[i]
                else:
                    # Nur Regularisierung
                    self.w = self.w - self.lr * self.w

            if epoch % 200 == 0:
                self.losses.append(total_loss / n)

    def predict(self, X):
        return np.sign(np.dot(X, self.w) + self.b).astype(int)

    def score(self, X, y):
        y_ = np.where(y <= 0, -1, 1)
        return np.mean(self.predict(X) == y_)

🐍 4/5b — Test: SoftMarginSVM für verschiedene C 
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

X, y = make_classification(
    n_samples=300,
    n_features=2,
    n_redundant=0,
    class_sep=0.8,
    random_state=42
)
X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42
)
scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)
X_test_s  = scaler.transform(X_test)

print(f"{'C':>8} | {'Train':>8} | {'Test':>8} | {'||w||':>8}")
print("-" * 40)
for C in [0.01, 0.1, 1.0, 10.0, 100.0]:
    svm = SoftMarginSVM(C=C, lr=0.0001, n_iter=2000)
    svm.fit(X_train_s, y_train)
    tr = svm.score(X_train_s, y_train)
    te = svm.score(X_test_s, y_test)
    nw = np.linalg.norm(svm.w)
    print(f"{C:>8} | {tr:>8.2%} | {te:>8.2%} | {nw:>8.4f}")

📊 Visualisierung — Entscheidungsgrenze für kleines vs. großes C

Bei kleinem C ist die Grenze fast eine gerade Linie, die viele Punkte falsch einsortiert (||w|| ≈ 0.008 — fast keine Trennung). Bei großem C schmiegt sich die Grenze enger an die Trainingsdaten an (||w|| ≈ 2.27), was die Trainings-Accuracy erhöht, aber das Risiko von Overfitting steigert.

Kleines C (z.B. 0.01)

Viele Margin-Verletzungen erlaubt. Breiter Margin, glattere Entscheidungsgrenze. Höhere Bias, niedrigere Variance — Gefahr von Underfitting.

↔
Großes C (z.B. 100)

Wenige Margin-Verletzungen erlaubt. Schmaler Margin, Entscheidungsgrenze passt sich stark an Trainingsdaten an. Niedrigere Bias, höhere Variance — Gefahr von Overfitting.

Stufe 5

🚀 C-Parameter mit sklearn und GridSearch

🐍 Schritt 1 — Pipeline & GridSearchCV ausführen 
from sklearn.svm import SVC
from sklearn.model_selection import GridSearchCV, StratifiedKFold
from sklearn.datasets import load_breast_cancer
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
import numpy as np

X, y = load_breast_cancer(return_X_y=True)

pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('svm',    SVC(kernel='linear'))
])

# C über mehrere Größenordnungen suchen (logarithmisch!)
param_grid = {'svm__C': [0.001, 0.01, 0.1, 1, 10, 100, 1000]}

cv = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)
grid = GridSearchCV(
    pipe,
    param_grid,
    cv=cv,
    scoring='accuracy',
    return_train_score=True
)
grid.fit(X, y)

print(f"Bestes C: {grid.best_params_['svm__C']}")
print(f"Beste CV Accuracy: {grid.best_score_:.4f}")

print(f"{'C':>8} | {'Train Acc':>10} | {'Val Acc':>10} | Diagnose")

for i, C in enumerate(param_grid['svm__C']):
    tr = grid.cv_results_['mean_train_score'][i]
    va = grid.cv_results_['mean_test_score'][i]
    gap = tr - va
    diag = "⚠️ Overfitting" if gap > 0.03 else ("📉 Underfitting" if va < 0.9 else "✅")

📊 Visualisierung — Bias-Variance-Tradeoff über C

Die Train-Kurve steigt mit wachsendem C kontinuierlich, während die Val-Kurve bei C≈0.1 ihr Maximum (0.9754) erreicht und danach wieder fällt — ab C=100 öffnet sich eine Lücke zu den Train-Scores (Overfitting). Der Sweet Spot liegt also nicht beim höchsten C, sondern dort, wo die Val-Kurve maximal ist.
