Stufe 2

🧠 Multi-Class SVM und SVR

Multi-Class Klassifikation

SVM ist nativ ein Binary Classifier. Für K Klassen gibt es zwei Strategien:

StrategieModelleVorhersagesklearn
One-vs-Rest (OvR) K Modelle (jede Klasse vs. alle anderen) Höchste Konfidenz gewinnt decision_function_shape='ovr'
One-vs-One (OvO) K(K-1)/2 Modelle (jedes Paar) Voting (wer gewinnt die meisten Duelle?) decision_function_shape='ovo'

sklearn's SVC nutzt intern OvO (genauer, schneller bei wenigen Klassen).

SVR — Support Vector Regression

SVR passt die SVM für Regressionsprobleme an: Statt Margin-Maximierung sucht man eine Funktion, die alle Punkte innerhalb eines ε-Schlauchs erklärt:

SVR Ziel: |y − f(x)| ≤ ε für alle Punkte
Punkte außerhalb des Schlauchs → Slack-Strafe (wie Soft-Margin)
ParameterBedeutung
CStrafe für Punkte außerhalb des ε-Schlauchs
epsilonBreite des Schlauchs — kein Fehler innerhalb
kernelGleiche Kernels wie SVC

⚙️ SVM-Workflow Checkliste

1
IMMER skalieren (StandardScaler oder MinMaxScaler)

SVM ist extrem empfindlich gegenüber Skalierung. Ohne Scaling dominiert die Feature mit der größten Varianz.

2
Kernel wählen: Erst linear versuchen

Bei n_features >> n_samples → linear oft besser. Sonst RBF als Standard.

3
C und gamma grob suchen (log-skaliert: 0.001, 0.01, ..., 1000)

GridSearchCV oder RandomizedSearchCV mit Pipeline.

4
Feinere Suche um den besten Bereich

Nach grobem Grid: feineres Grid im besten Bereich.

5
Finales Modell auf Trainingsdaten fitten, auf Testdaten evaluieren

Testdaten nur einmal anfassen!

Stufe 4

🛠️ Von Scratch: LinearSVC via SGD

Für sehr große Datensätze ist kernelbasierter SVC zu langsam. SGDClassifier(loss='hinge') löst dasselbe Problem, aber mit stochastischem Gradient Descent:

🐍 4/5a — Klasse: LinearSVM_SGD 
import numpy as np

class LinearSVM_SGD:
    """
    Lineare SVM via Stochastischem Gradient Descent.
    Skaliert auf große Datensätze (äquivalent zu LinearSVC).
    """

    def __init__(self, C=1.0, lr=0.01, n_epochs=100, random_state=42):
        self.C = C
        self.lr = lr
        self.n_epochs = n_epochs
        self.rng = np.random.default_rng(random_state)

    def fit(self, X, y):
        y_ = np.where(y <= 0, -1, 1)
        n, d = X.shape
        self.w = np.zeros(d)
        self.b = 0.0

        for epoch in range(self.n_epochs):
            # Lernrate abkühlen lassen (Learning Rate Schedule)
            lr_t = self.lr / (1 + epoch * 0.1)

            # Zufällige Reihenfolge
            indices = self.rng.permutation(n)
            for i in indices:
                xi, yi = X[i], y_[i]
                if yi * (np.dot(self.w, xi) + self.b) < 1:
                    # Hinge-Verlust: Update Richtung
                    self.w = (1 - lr_t) * self.w + lr_t * self.C * yi * xi
                    self.b += lr_t * self.C * yi
                else:
                    # Nur Gewichts-Decay
                    self.w = (1 - lr_t) * self.w

    def decision_function(self, X):
        return np.dot(X, self.w) + self.b

    def predict(self, X):
        return np.sign(self.decision_function(X)).astype(int)

    def score(self, X, y):
        y_ = np.where(y <= 0, -1, 1)
        return np.mean(self.predict(X) == y_)

Test: Vergleich der Scratch-Implementierung mit sklearns LinearSVC auf dem Breast-Cancer-Datensatz:

🐍 4/5b — Test: LinearSVM_SGD vs. sklearn LinearSVC 
from sklearn.svm import LinearSVC
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score

X, y = load_breast_cancer(return_X_y=True)
y_pm = np.where(y == 0, -1, 1)
X_train, X_test, y_train, y_test = train_test_split(
    X,
    y_pm,
    test_size=0.2,
    random_state=42
)
scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)
X_test_s  = scaler.transform(X_test)

# Scratch
scratch = LinearSVM_SGD(C=1.0, n_epochs=100)
scratch.fit(X_train_s, y_train)
print(f"Scratch LinearSVM: {scratch.score(X_test_s, y_test):.2%}")

# sklearn LinearSVC
lsvc = LinearSVC(
    C=1.0,
    max_iter=2000
)
lsvc.fit(X_train_s, y_train)
print(f"sklearn LinearSVC: {accuracy_score(y_test, lsvc.predict(X_test_s)):.2%}")

🚀 Vollständiger SVM-Workflow

🐍 Schritt 1 — Multi-Class SVC mit GridSearchCV (Iris) 
from sklearn.svm import SVC
from sklearn.model_selection import GridSearchCV, StratifiedKFold, train_test_split
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
import numpy as np

X, y = load_iris(return_X_y=True)

pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('svc',    SVC(
        decision_function_shape='ovr',
        probability=True
    ))
])

param_grid = {
    'svc__C':      [0.1, 1, 10, 100],
    'svc__kernel': ['linear', 'rbf'],
    'svc__gamma':  ['scale', 0.1, 0.01],
}
cv = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)
gs = GridSearchCV(
    pipe,
    param_grid,
    cv=cv,
    scoring='accuracy',
    n_jobs=-1
)
gs.fit(X, y)

print(f"Beste Parameter: {gs.best_params_}")
print(f"CV Accuracy:     {gs.best_score_:.4f}")

🐍 Schritt 3 — SVR mit GridSearchCV (Diabetes) 
from sklearn.svm import SVR
from sklearn.datasets import load_diabetes

X_r, y_r = load_diabetes(return_X_y=True)

svr_pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('svr',    SVR(kernel='rbf'))
])
svr_params = {
    'svr__C':       [1, 10, 100],
    'svr__epsilon': [0.1, 0.5, 1.0],
    'svr__gamma':   ['scale', 0.01],
}
gs_r = GridSearchCV(
    svr_pipe,
    svr_params,
    cv=5,
    scoring='r2',
    n_jobs=-1
)
gs_r.fit(X_r, y_r)
print(f"Beste SVR Parameter: {gs_r.best_params_}")
print(f"Bestes R² (CV):      {gs_r.best_score_:.4f}")
