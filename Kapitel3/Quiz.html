Hyperebene & Margin

Q1 Was ist eine Hyperebene und wie lautet ihre allgemeine Gleichung?
Eine Hyperebene in n Dimensionen ist eine (n-1)-dimensionale Fläche. Gleichung: wᵀx + b = 0 — w ist der Normalenvektor (senkrecht zur Ebene), b der Bias-Term. In 2D ist es eine Gerade, in 3D eine Ebene.
Q2 Was sind Support Vectors?
Support Vectors sind die Datenpunkte, die direkt auf dem Rand des Margins liegen (wᵀxᵢ + b = ±1). Nur sie bestimmen die Hyperebene — alle anderen Punkte könnten entfernt werden, ohne das Modell zu ändern!
Q3 Wie groß ist der Margin einer SVM? Warum wird er maximiert?
Margin-Breite = 2 / ||w||. Maximaler Margin entspricht dem Minimieren von ||w||. Ein großer Margin bedeutet Robustheit — neue Punkte können weiter von der Grenze abweichen, ohne falsch klassifiziert zu werden (bessere Generalisierung).
Q4 Wie klassifiziert eine SVM einen neuen Punkt x?
f(x) = sign(wᵀx + b)
• wᵀx + b > 0 → Klasse +1
• wᵀx + b < 0 → Klasse −1
Der Abstand zur Hyperebene ist |wᵀx + b| / ||w||.
Q5 Wie lautet das Optimierungsproblem der Hard-Margin SVM?
Minimiere: ½ · ||w||²
unter: yᵢ · (wᵀxᵢ + b) ≥ 1 für alle i
Die Bedingung stellt sicher, dass alle Punkte korrekt klassifiziert außerhalb der Margin-Zone liegen.

Soft Margin & C-Parameter

Q6 Warum braucht man Soft-Margin statt Hard-Margin?
Reale Daten sind selten perfekt linear trennbar — es gibt Ausreißer, Rauschen und überlappende Klassen. Hard-Margin SVM hat keine Lösung wenn Daten nicht trennbar sind. Soft-Margin erlaubt Margin-Verletzungen durch Slack-Variablen ξᵢ ≥ 0.
Q7 Was bedeutet ein kleines C vs. großes C?
Kleines C (z.B. 0.01): Viele Fehler erlaubt → breiter Margin → starke Regularisierung → Underfitting-Gefahr
Großes C (z.B. 1000): Wenige Fehler → schmaler Margin → schwache Regularisierung → Overfitting-Gefahr
C ist der Kehrwert der Regularisierungsstärke.
Q8 Was ist der Hinge Loss?
L = max(0, 1 − y · f(x))
• Korrekt außerhalb Margin: Loss = 0
• Korrekt im Margin: kleiner positiver Loss
• Falsch klassifiziert: großer Loss
Die SVM minimiert: ½||w||² + C · Σ max(0, 1 − yᵢfᵢ)
Q9 Was sind Slack-Variablen ξᵢ?
ξᵢ misst das Ausmaß der Margin-Verletzung: ξᵢ=0 (korrekt, außerhalb), 0<ξᵢ≤1 (korrekt, im Margin), ξᵢ>1 (falsch klassifiziert). Die Summe Σξᵢ wird in der Zielfunktion mit Gewicht C bestraft.

Kernel-Trick

Q10 Was ist die Grundidee des Kernel-Tricks?
In der dualen SVM-Formulierung braucht man nur Skalarprodukte ⟨xᵢ, xⱼ⟩. Ein Kernel K(xᵢ, xⱼ) = ⟨φ(xᵢ), φ(xⱼ)⟩ berechnet das Skalarprodukt im höherdimensionalen Raum implizit — ohne φ(x) explizit auszurechnen. Man erhält nichtlineare Entscheidungsgrenzen bei linearer Rechenaufwand.
Q11 Schreibe die Formel des RBF-Kernels und erkläre γ.
K(x, z) = exp(−γ · ||x − z||²)
γ steuert die "Reichweite" eines Support Vectors:
• Kleines γ → weit → glatte Grenze → Underfitting
• Großes γ → eng → gezackte Grenze → Overfitting
Standard: gamma='scale' = 1/(n_features · Var(X))
Q12 Wann verwendest du 'linear' vs. 'rbf' Kernel?
Linear: Wenn n_features ≫ n_samples (z.B. Text-Klassifikation), wenn lineare Trennbarkeit wahrscheinlich ist, oder bei sehr großen Datensätzen (schneller).
RBF: Standard-Wahl für unbekannte, nichtlineare Strukturen, mittelgroße Datensätze.
Q13 Wie sieht die Vorhersagefunktion der Kernel-SVM aus?
f(x) = sign(Σᵢ αᵢ · yᵢ · K(xᵢ, x) + b)
Die Summe läuft nur über die Support Vectors (αᵢ > 0). K(xᵢ, x) ist der Kernel zwischen dem i-ten Support Vector und dem Testpunkt.

SVC professionell

Q14 Warum muss man VOR der SVM zwingend skalieren?
SVM basiert auf Distanzen und Skalarprodukten. Features mit großer Varianz dominieren die Berechnungen. StandardScaler stellt gleiche Wichtung aller Features sicher. Ohne Scaling kann die Accuracy drastisch schlechter sein.
Q15 Wie suchst du C und gamma effizient?
Log-skaliert: C ∈ {0.001, 0.01, 0.1, 1, 10, 100, 1000}
Gamma ∈ {0.001, 0.01, 0.1, 'scale', 'auto'}
Mit GridSearchCV(cv=StratifiedKFold(5)) und Pipeline(Scaler + SVC).
Wichtig: C und gamma zusammen suchen — sie interagieren!
Q16 Was ist One-vs-Rest (OvR) vs. One-vs-One (OvO)?
OvR: K Binär-Modelle (jede Klasse vs. alle anderen) → K Modelle
OvO: Jedes Klassenpaar → K(K-1)/2 Modelle, Voting
sklearn SVC nutzt intern OvO. Für K=3: 3 Modelle. Für K=10: 45 Modelle.
Q17 Wann ist SVM eine schlechte Wahl?
❌ Sehr große Datensätze (n > 100k) — O(n²) bis O(n³) Komplexität
❌ Wenn Interpretierbarkeit nötig ist (Black Box)
❌ Sehr viele Klassen (OvO wird explosiv)
❌ Wenn Wahrscheinlichkeiten wichtig sind (kalibrierte Probs nur mit probability=True, langsam)
Q18 Was ist SVR? Welche Parameter hat es zusätzlich?
SVR (Support Vector Regression) passt SVM für Regressionsprobleme an. Zusätzlicher Parameter: epsilon — Breite des ε-Schlauchs. Punkte innerhalb des Schlauchs erzeugen keinen Verlust. C bestraft Punkte außerhalb des Schlauchs.
Q19 Was gibt svm.decision_function(X) zurück?
Den vorzeichenbehafteten Abstand jedes Punkts zur Entscheidungshyperebene (skaliert auf den Margin). Positiv → Klasse +1, Negativ → Klasse −1. Der Betrag gibt die Konfidenz an — weiter von der Grenze = sicherer.
Q20 Du trainierst eine SVM, aber die Konvergenz schlägt fehl (max_iter Warnung). Was tust du?
1. Daten skalieren (falls noch nicht: StandardScaler)
2. max_iter erhöhen (z.B. 10000)
3. C verkleinern (numerische Probleme bei sehr großem C)
4. Bei sehr großen Daten: LinearSVC oder SGDClassifier(loss='hinge') statt SVC verwenden — diese skalieren besser.
