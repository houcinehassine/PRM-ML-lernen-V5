📐 Hyperebene & Margin

Wie trennt eine Support Vector Machine zwei Klassen? Was macht die Trennlinie zur optimalen Trennlinie — und welche Punkte bestimmen sie?

Stufe 1

🎯 Ziel & Kontext

Das Problem: Viele Trennlinien, welche ist "besser"?

Stell dir zwei Klassen von Punkten in 2D vor — Kreise und Kreuze. Es gibt unendlich viele Geraden, die sie trennen. Welche soll man wählen?

× × × | ○ ○
× × | ○ ○ ○
× × × | ○ ○
↑ viele gültige Trennlinien

Die SVM-Antwort: Wähle die Gerade, die den maximalen Abstand (Margin) zu den nächsten Punkten beider Klassen hat. Das ist die Hyperebene mit maximalem Margin.

Kernfrage: Warum ist maximaler Margin besser — und was sind "Support Vectors"?
Stufe 2

🧠 Theorie: Hyperebene, Margin, Support Vectors

Die Hyperebene

Eine Hyperebene in n Dimensionen ist eine (n-1)-dimensionale Fläche:

DimensionHyperebeneGleichung
2DGeradew₁x₁ + w₂x₂ + b = 0
3DEbenew₁x₁ + w₂x₂ + w₃x₃ + b = 0
nDHyperebenewᵀx + b = 0

Allgemein: wᵀx + b = 0 — dabei ist w der Normalenvektor (zeigt senkrecht zur Ebene) und b der Bias-Term.

Margin und Support Vectors

Margin: Der Abstand zwischen der Hyperebene und den nächsten Datenpunkten jeder Klasse. Die SVM maximiert diesen Abstand.

Support Vectors: Die Datenpunkte, die direkt auf dem Rand des Margins liegen. Nur sie bestimmen die Hyperebene — alle anderen Punkte sind irrelevant!

Margin-Breite: 2 / ||w|| — maximaler Margin bedeutet ||w|| minimieren.

Klassifikationsentscheidung

Für einen neuen Punkt x:

  • wᵀx + b > 0 → Klasse +1
  • wᵀx + b < 0 → Klasse −1
  • wᵀx + b = 0 → auf der Hyperebene

Die Margin-Grenzen liegen bei wᵀx + b = +1 und wᵀx + b = −1.

Warum maximaler Margin besser ist

Generalisierungs-Theorie: Eine größere Margin bedeutet, dass neue Punkte weiter von der Entscheidungsgrenze entfernt sind. Das Modell ist robuster gegenüber kleinen Datenschwankungen. Mathematisch: VC-Dimension sinkt mit steigendem Margin → bessere Generalisierung.
Stufe 3

⚙️ Das SVM-Optimierungsproblem

Die Hard-Margin SVM löst folgendes Optimierungsproblem:

Minimiere: ½ · ||w||²
unter: yᵢ · (wᵀxᵢ + b) ≥ 1 für alle i

Die Bedingung yᵢ · (wᵀxᵢ + b) ≥ 1 stellt sicher, dass alle Punkte korrekt klassifiziert und außerhalb der Margin-Zone liegen.

1
Datenpunkte mit Labels yᵢ ∈ {-1, +1}

Nicht wie üblich 0/1 — SVM verwendet −1/+1 für die Math.

2
Quadratisches Optimierungsproblem lösen (QP)

Gesucht: w und b. In der Praxis nutzt man das duale Problem mit Lagrange-Multiplikatoren (αᵢ).

3
Support Vectors identifizieren

Punkte mit αᵢ > 0 sind Support Vectors — nur sie tragen zur Entscheidungsfunktion bei.

4
Entscheidungsfunktion: f(x) = sign(Σ αᵢ yᵢ ⟨xᵢ, x⟩ + b)

Die duale Form erlaubt den Kernel-Trick (Thema 3).

Stufe 4

🛠️ Von Scratch: Hard-Margin SVM via Gradient Descent

Wir implementieren eine vereinfachte Hard-Margin SVM mit Gradient Descent (für linear separierbare Daten):

🐍 4/5a — Klasse: HardMarginSVM 
import numpy as np

class HardMarginSVM:
    """
    Lineare SVM (Hard-Margin) via Subgradient Descent.
    Nur für linear separierbare Daten geeignet.
    """

    def __init__(self, lr=0.01, n_iter=1000):
        self.lr = lr
        self.n_iter = n_iter

    def fit(self, X, y):
        # Labels müssen -1 oder +1 sein
        y_ = np.where(y <= 0, -1, 1)
        n, d = X.shape
        self.w = np.zeros(d)
        self.b = 0.0

        for _ in range(self.n_iter):
            for i, xi in enumerate(X):
                # Wenn Punkt NICHT korrekt im Margin: Gradient-Schritt
                if y_[i] * (np.dot(self.w, xi) + self.b) < 1:
                    self.w += self.lr * (y_[i] * xi - 2 * (1/self.n_iter) * self.w)
                    self.b += self.lr * y_[i]
                else:
                    # Nur Regularisierung
                    self.w -= self.lr * (2 * (1/self.n_iter) * self.w)

    def predict(self, X):
        return np.sign(np.dot(X, self.w) + self.b).astype(int)

    def score(self, X, y):
        y_ = np.where(y <= 0, -1, 1)
        return np.mean(self.predict(X) == y_)

    @property
    def margin(self):
        """Margin-Breite = 2 / ||w||"""
        norm = np.linalg.norm(self.w)
        return 2 / norm if norm > 0 else float('inf')

🐍 4/5b — Test: HardMarginSVM 
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

X, y = make_classification(
    n_samples=200,
    n_features=2,
    n_redundant=0,
    n_clusters_per_class=1,
    class_sep=2.0,
    random_state=42
)
y = np.where(y == 0, -1, 1)

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42
)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test  = scaler.transform(X_test)

svm = HardMarginSVM(lr=0.001, n_iter=2000)
svm.fit(X_train, y_train)

print(f"Train Accuracy: {svm.score(X_train, y_train):.2%}")
print(f"Test  Accuracy: {svm.score(X_test, y_test):.2%}")
print(f"Margin-Breite:  {svm.margin:.4f}")
print(f"||w|| = {np.linalg.norm(svm.w):.4f}")
print(f"Anzahl Support Vectors: ~ (nur sklearn gibt exakte Zahl)")

ax.plot(x_vals, y_vals, 'k-', label='Hyperebene')
ax.plot(x_vals, y_vals + offset, 'k--', alpha=.5, label='Margin')
ax.plot(x_vals, y_vals - offset, 'k--', alpha=.5)
ax.set_title(f"Hard-Margin SVM von Scratch (Margin-Breite={svm.margin:.3f})")
ax.legend()
plt.show()

🚀 SVM mit sklearn — Support Vectors inspizieren

🐍 Schritt 1 — Daten vorbereiten & SVC trainieren 
from sklearn.svm import SVC
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import numpy as np

# Linear separierbare Daten
X, y = make_classification(
    n_samples=200,
    n_features=2,
    n_redundant=0,
    n_clusters_per_class=1,
    class_sep=2.0,
    random_state=42
)

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42
)
scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)
X_test_s  = scaler.transform(X_test)

# Hard-Margin SVM (C sehr groß ≈ kein Soft-Margin)
svm = SVC(
    kernel='linear',
    C=1e6
)
svm.fit(X_train_s, y_train)

print(f"Accuracy: {svm.score(X_test_s, y_test):.2%}")

📊 Visualisierung — Hyperebene, Margin & Support Vectors

Die Streudiagramm-Darstellung der beiden Klassen zeigt die Trenngerade (wᵀx + b = 0) in der Mitte, flankiert von zwei gestrichelten Margin-Linien (wᵀx + b = ±1). Die Punkte, die genau auf diesen Margin-Linien liegen, sind die Support Vectors — meist nur eine Handvoll Punkte (hier 9 von 140). Alle anderen Punkte liegen außerhalb des Margins und hätten keinen Einfluss, würde man sie entfernen und das Modell neu trainieren.
