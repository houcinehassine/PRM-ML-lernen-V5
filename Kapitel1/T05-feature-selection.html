🔍 Feature Selection

Mehr Features = besseres Modell? Falsch. Der Fluch der Dimensionalität und wie wir die informativsten Features auswählen — VarianceThreshold, SelectKBest und RFE.

🎯
Einleitung
Ziel & Kontext

Warum Features entfernen?

Intuitiv denkt man: mehr Informationen = besser. Aber in der Praxis gilt: irrelevante und redundante Features schaden dem Modell.

  • Overfitting: Das Modell lernt Rauschen statt echte Muster
  • Fluch der Dimensionalität: In hohen Dimensionen werden alle Datenpunkte "weit voneinander entfernt" — Abstände verlieren ihre Bedeutung
  • Rechenzeit: Mehr Features = mehr Berechnungen
  • Interpretierbarkeit: Weniger Features = verständlicheres Modell

Der Fluch der Dimensionalität — konkret erklärt

Stell dir vor, du hast 100 Datenpunkte, gleichmäßig verteilt in einem d-dimensionalen Würfel [0,1]ᵈ.

Dimensionen (d)Ø Abstand zum nächsten NachbarnProblem
1≈ 0.010Punkte liegen nah beieinander ✓
2≈ 0.052Abstände wachsen
5≈ 0.220Nächster Nachbar schon 22% des Bereichs entfernt
10≈ 0.430Nächster Nachbar fast 50% des Bereichs entfernt
100≈ 0.980Alle Punkte sind quasi gleich weit weg!

Formel für den durchschnittlichen Abstand zum nächsten Nachbar bei n Punkten in d Dimensionen: d_min ≈ (1/n)^(1/d). Bei n=100, d=100: (0.01)^(0.01) = 0.955.

Folge für k-NN

k-NN basiert auf Abständen. Wenn alle Abstände ähnlich groß sind, hat "der nächste Nachbar" keine Bedeutung mehr. Das Modell entscheidet dann quasi zufällig. Lösung: Feature Selection.

Drei Kategorien von Feature-Selection-Methoden

KategorieWie es funktioniertBeispieleWann
FilterBewertet Features unabhängig vom Modell anhand statistischer Maße — schnellVarianceThreshold, SelectKBest, KorrelationsmatrixAls erster Schritt, große Datensätze
WrapperTrainiert Modell mit verschiedenen Feature-Subsets — aufwändig aber genauerRFE (Recursive Feature Elimination), Forward/Backward SelectionWenn Rechenzeit verfügbar
EmbeddedFeature-Selection während des Trainings integriert — kein Extra-SchrittLasso (L1), Feature Importance (RF), ElasticNetEmpfohlen für reguläre ML-Pipelines

Drei konkrete Methoden auf dieser Seite — jede von Theorie bis sklearn:

1️⃣ VarianceThreshold

Filter — entfernt Features mit Varianz unter einem Schwellenwert. → Zu Methode 1

2️⃣ SelectKBest

Filter — wählt die K Features mit dem höchsten statistischen Score. → Zu Methode 2

3️⃣ RFE / RFECV

Wrapper — trainiert iterativ und entfernt das schwächste Feature. → Zu Methode 3

Im Abschnitt Vergleich stellen wir Filter, Wrapper und Embedded (Random Forest Feature Importance) gegenüber.

Kernfrage

Welche Features tragen wirklich zur Vorhersage bei — und welche kann ich getrost entfernen?

Lernziel

Du kennst VarianceThreshold (Filter), SelectKBest (statistischer Test) und RFE (Wrapper) und weißt wann du welche Methode einsetzt.

1
Filter: Varianz-Filter (VarianceThreshold)

Entfernt Features, deren Varianz unter einem Schwellenwert liegt — die einfachste Filter-Methode.

🧠 Theorie ⚙️ Algorithmus 🛠️ Von Scratch 🚀 Mit sklearn
🧠
Theorie
VarianceThreshold — Intuition

Entfernt Features, deren Varianz unter einem Schwellenwert liegt. Features mit sehr geringer Varianz liefern kaum Information — sie sind fast konstant.

Idee

Feature mit Varianz ≈ 0: Fast alle Werte sind gleich → kein Informationsgehalt für das Modell. Beispiel: Feature "Staatsbürgerschaft" mit 99% "DE" hat Var ≈ 0.01 → entfernen.

Merksatz

VarianceThreshold ist eine reine "Vorab-Säuberung" — sie betrachtet jedes Feature einzeln und unabhängig von y. Sie erkennt nur konstante/quasi-konstante Features, keine schwachen Zusammenhänge zu y.

⚙️
Algorithmus
VarianceThreshold — Schritt für Schritt
1
Varianz pro Feature berechnen (Fit)

Für jede Spalte j: Var(X_j) = (1/N) × Σ(x_i − μ_j)²

2
Mit Schwellenwert vergleichen

Behalte Feature j, wenn Var(X_j) ≥ threshold.

3
Feature-Maske erstellen und anwenden (Transform)

Erstelle Boolean-Maske: [True, False, True, ...] und selektiere entsprechende Spalten.

🛠️
Von Scratch
VarianceThreshold selbst implementieren
🐍 1/2 — Klasse: VarianceThreshold_Scratch
import numpy as np

class VarianceThreshold_Scratch:
    """Entfernt Features mit Varianz unter dem Schwellenwert."""

    def __init__(self, threshold=0.0):
        self.threshold = threshold

    def fit(self, X):
        self.variances_ = X.var(axis=0)          # Varianz jeder Spalte
        self.mask_ = self.variances_ >= self.threshold
        self.support_ = np.where(self.mask_)[0]  # Indizes der behaltenen Features
        return self

    def transform(self, X):
        return X[:, self.mask_]

    def fit_transform(self, X):
        return self.fit(X).transform(X)

2
Filter: Statistischer Test (SelectKBest)

Bewertet jedes Feature anhand einer statistischen Teststatistik und wählt die K besten aus.

🧠 Theorie ⚙️ Algorithmus 🛠️ Von Scratch 🚀 Mit sklearn
🧠
Theorie
SelectKBest — ANOVA F-Wert
ANOVA F-Wert (f_classif)
F = Varianz zwischen Gruppen / Varianz innerhalb Gruppen
Hoher F-Wert → das Feature trennt die Klassen gut auseinander Niedriger F-Wert → das Feature unterscheidet sich kaum zwischen Klassen
Score-FunktionFür welche AufgabeMisst
f_classifKlassifikationANOVA F-Wert (lineare Abhängigkeit zwischen Feature und Klasse)
mutual_info_classifKlassifikationMutual Information (auch nicht-lineare Zusammenhänge)
f_regressionRegressionF-Wert für lineare Korrelation
chi2Klassifikation (nur X ≥ 0!)Chi-Quadrat-Test — für kategoriale Features nach OHE
Merksatz

Anders als VarianceThreshold betrachtet SelectKBest den Zusammenhang zwischen Feature und Zielvariable y — dadurch werden Features erkannt, die zwar streuen, aber nichts mit y zu tun haben.

⚙️
Algorithmus
SelectKBest mit ANOVA F-Wert — Schritt für Schritt
1
Gruppenstatistiken berechnen (Fit)

Berechne für jedes Feature j den Mittelwert μ_k(j) und die Varianz σ²_k(j) pro Klasse k.

2
Between-Group-Varianz (SSB)

SSB(j) = Σₖ nₖ × (μ_k(j) − μ_gesamt(j))² — wie stark unterscheiden sich die Klassenmittelwerte?

3
Within-Group-Varianz (SSW)

SSW(j) = Σₖ Σᵢ∈k (x_i(j) − μ_k(j))² — wie stark streuen die Werte innerhalb jeder Klasse?

4
F-Wert berechnen

F(j) = (SSB/(K−1)) / (SSW/(N−K)) — hoher F = Feature trennt Klassen gut.

5
Top-K Features auswählen (Transform)

Sortiere alle Features nach F-Wert, wähle die K größten.

🛠️
Von Scratch
SelectKBest (ANOVA) selbst implementieren
🐍 1/2 — Klasse: SelectKBest_ANOVA
class SelectKBest_ANOVA:
    """Wählt K beste Features anhand des ANOVA F-Werts."""

    def __init__(self, k=10):
        self.k = k

    def fit(self, X, y):
        classes = np.unique(y)
        K = len(classes)
        N = len(X)
        n_features = X.shape[1]

        mu_gesamt = X.mean(axis=0)   # Gesamt-Mittelwert pro Feature
        self.scores_ = np.zeros(n_features)

        for j in range(n_features):
            # Between-group sum of squares (SSB)
            SSB = sum(
                np.sum(y == k) * (X[y == k, j].mean() - mu_gesamt[j])**2
                for k in classes
            )
            # Within-group sum of squares (SSW)
            SSW = sum(
                np.sum((X[y == k, j] - X[y == k, j].mean())**2)
                for k in classes
            )
            # F-Wert: große Streuung zwischen Klassen, kleine innerhalb = gut
            MSB = SSB / (K - 1)     # Mean Square Between
            MSW = SSW / (N - K)     # Mean Square Within
            self.scores_[j] = MSB / MSW if MSW > 0 else 0.0

        # Top-K Indizes (absteigend sortiert)
        self.top_k_idx_ = np.argsort(self.scores_)[::-1][:self.k]
        return self

    def transform(self, X):
        return X[:, self.top_k_idx_]

    def fit_transform(self, X, y):
        return self.fit(X, y).transform(X)

3
Wrapper: Rekursive Eliminierung (RFE / RFECV)

Trainiert ein Modell, entfernt das schwächste Feature, trainiert erneut — und wiederholt das, bis die gewünschte Anzahl Features übrig bleibt.

🧠 Theorie ⚙️ Algorithmus 🚀 Mit sklearn
🧠
Theorie
RFE — Intuition

RFE (Recursive Feature Elimination) ist ein Wrapper: es nutzt ein echtes Modell, um die Wichtigkeit jedes Features zu beurteilen — und entfernt iterativ das schwächste.

Vorteil gegenüber Filter

Filter-Methoden bewerten Features unabhängig voneinander. RFE berücksichtigt Wechselwirkungen: wenn Feature A und B korreliert sind, erkennt RFE, dass eines davon redundant ist. Nachteil: k×Training statt 1×Training.

Merksatz

RFE braucht ein Modell mit Feature-Wichtigkeiten (z.B. coef_ bei linearen Modellen, feature_importances_ bei Bäumen). Es gibt von RFE keine sinnvolle "from scratch"-Mini-Version — der Algorithmus ist "trainiere das Modell wiederholt", was nur mit einem echten Schätzer Sinn ergibt. Deshalb springen wir direkt zu sklearn.

⚙️
Algorithmus
RFE — Schritt für Schritt
1
Modell auf allen Features trainieren

Nutze ein Modell mit Feature Importance (SVM: Koeffizienten, RF: Importances).

2
Schwächstes Feature identifizieren

Das Feature mit dem kleinsten Koeffizienten / kleinster Importance → markieren als "entfernt".

3
Mit verbleibendem Feature-Set neu trainieren

Wiederhole Schritt 1 und 2 mit den verbleibenden Features.

4
Wiederholen bis n_features_to_select übrig

Jede Iteration entfernt das schwächste Feature. Ergebnis: geordnetes Ranking aller Features.

RFECV erweitert das: statt eine feste Anzahl Features vorzugeben, testet es per Cross-Validation jede mögliche Anzahl und wählt die mit der besten Validierungs-Performance.

🚀
Mit sklearn
RFE & RFECV — professionell nutzen
🐍 Schritt 1 — Skalieren & RFE mit SVM

In Pipeline einbauen

🐍 Schritt — Pipelines vergleichen (Filter vs. Embedded)
from sklearn.pipeline import Pipeline
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# Vergleich: Mit vs. ohne Feature Selection
pipe_alle = Pipeline([
    ('scaler',  StandardScaler()),
    ('clf',     SVC(kernel='rbf', random_state=42))
])

pipe_rfe = Pipeline([
    ('scaler',    StandardScaler()),
    ('selector',  SelectKBest(score_func=f_classif, k=10)),
    ('clf',       SVC(kernel='rbf', random_state=42))
])

pipe_rf_importance = Pipeline([
    ('scaler',    StandardScaler()),
    ('clf',       RandomForestClassifier(n_estimators=100, random_state=42))
])

for name, pipe in [('Alle 30 Features (SVM)',     pipe_alle),
                   ('SelectKBest k=10 (SVM)',      pipe_rfe),
                   ('Random Forest (Embedded)',     pipe_rf_importance)]:
    pipe.fit(X_train, y_train)
    acc = accuracy_score(y_test, pipe.predict(X_test))
    print(f"{name:<35}: {acc:.4f}")

Bonus: t-SNE für Visualisierung (nicht für Feature Selection!)

t-SNE (t-distributed Stochastic Neighbor Embedding) reduziert hochdimensionale Daten auf 2D zur Visualisierung. Es ist kein Feature-Selection-Tool — die 2D-Koordinaten haben keine direkte Bedeutung für ein ML-Modell.

Fallen: t-SNE als Feature Extraction

t-SNE-Koordinaten können nicht für Training genutzt werden, weil: (1) t-SNE ist nicht parametrisch — neue Datenpunkte können nicht transformiert werden. (2) Die Geometrie ist nicht linear interpretierbar. → Für echte Dimensionsreduktion: PCA (linear) oder Autoencoder (nicht-linear).

⚠️
Selektor auf ganzen Datensatz fitten

SelectKBest muss wie jeder Scaler nur auf X_train gefittet werden. Auf X_test nur transform().

✅ Nutze Pipeline — die handhabt fit/transform automatisch korrekt
⚠️
Garbage In / Garbage Out

Feature Selection entfernt rauschartige Features — aber wenn alle Features qualitativ schlecht sind (falsch gemessen, falsch erhoben), hilft auch die beste Selektion nicht. Schlechte Eingabe = schlechte Ausgabe, egal wie raffiniert das Modell.

✅ Domain Knowledge vor Feature Engineering: Macht dieses Feature inhaltlich Sinn? Ist die Messung verlässlich?
⚠️
t-SNE als Feature Extraction verwenden

t-SNE ist ein Visualisierungstool, kein Feature-Extraktions-Tool. Die 2D-Koordinaten können nicht für Training genutzt werden (nicht parametrisch, keine transform-Methode für neue Daten).

✅ Für Dimensionsreduktion vor Training: PCA (linear, schnell) oder Autoencoder (nicht-linear). t-SNE nur für Plots.
