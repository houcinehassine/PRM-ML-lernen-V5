train_test_split

Q1 Was ist der Zweck von train_test_split?
Der Datensatz wird in Training- und Test-Set aufgeteilt, damit das Modell auf Daten bewertet wird, die es nie zuvor gesehen hat. Würden dieselben Daten zum Training und zur Evaluation genutzt, würde man Auswendiglernen statt Generalisierung messen.
Q2 Was bewirkt stratify=y?
Die Klassenverteilung aus dem Originaldatensatz wird im Train- und Test-Set erhalten. Wichtig bei unbalancierten Datensätzen — ohne stratify könnte eine seltene Klasse zufällig im Test-Set fehlen.
Q3 Warum muss der Scaler NACH dem Split gefittet werden?
Wird der Scaler auf dem ganzen Datensatz gefittet (inkl. Testdaten), enthält er statistische Information aus den Testdaten (min, max, μ, σ). Dann "kennt" das Modell die Testdaten indirekt → Data Leakage. Scaler immer nur auf X_train fitten.
Q4 Was passiert intern bei train_test_split?
1. Index-Array [0, ..., N-1] erstellen
2. Indizes zufällig mischen (shuffle)
3. n_test = int(N × test_size) berechnen
4. Erste n_test Indizes → Test, Rest → Training
5. X und y mit diesen Indizes slicen

Normalisierung & Scaling

Q5 Schreibe die Min-Max-Formel auf.
x' = (x - x_min) / (x_max - x_min)
Resultat liegt in [0, 1]. x_min und x_max werden aus den Trainingsdaten berechnet.
Q6 Schreibe die Z-Score (Standardisierungs) Formel auf.
x' = (x - μ) / σ
μ = Mittelwert, σ = Standardabweichung (beides aus Trainingsdaten). Resultat hat Mittelwert 0 und Std 1.
Q7 Wann ist RobustScaler besser als StandardScaler?
Bei Ausreißern. RobustScaler nutzt Median und IQR statt Mean und Std — diese sind robust gegenüber Extremwerten. StandardScaler wird durch Ausreißer stark beeinflusst und quetscht alle normalen Werte zusammen.
Q8 Welche Algorithmen benötigen Feature Scaling?
✅ Benötigen Scaling: k-NN, SVM, Logistische Regression, Neuronale Netze, Gradient Descent-basierte Methoden
❌ Brauchen kein Scaling: Entscheidungsbäume, Random Forest, Gradient Boosting (baumbasiert, splitten nach Schwellenwerten)
Q9 Berechne: Feature = [10, 20, 30]. MinMax-Normalisierung von 20?
min=10, max=30
x' = (20 - 10) / (30 - 10) = 10/20 = 0.5
Q10 Du hast einen Testpunkt x=35, dein Train-MinMax: min=10, max=30. Was ist x'?
x' = (35 - 10) / (30 - 10) = 25/20 = 1.25
Der Wert liegt außerhalb [0,1] — das ist möglich und korrekt! Testdaten können außerhalb des Trainingsbereichs liegen. Kein Fehler.

Encoding

Q11 Was ist das Problem mit Label-Encoding für nominale Kategorien?
Label-Encoding weist Zahlen zu (rot=0, blau=1, grün=2). Der Algorithmus interpretiert das als Ordnung: grün > blau > rot — die gar nicht existiert. Nur für ordinale Kategorien (klein < mittel < groß) korrekt.
Q12 Was ist die Dummy-Variable-Trap?
Bei One-Hot-Encoding von K Kategorien entstehen K Spalten. Die letzte Spalte ist immer durch die anderen bestimmbar (wenn alle anderen 0 sind, muss sie 1 sein → Multikollinearität). Lösung: drop='first' → nur K-1 Spalten.
Q13 Für welche Variable nutzt man LabelEncoder in sklearn?
Nur für die Zielvariable y. Für Feature-Spalten X nutzt man OneHotEncoder (nominal) oder OrdinalEncoder (ordinal).

Feature Selection

Q14 Was macht VarianceThreshold?
Entfernt Features, deren Varianz unter einem Schwellenwert liegt. Fast konstante Features (Var ≈ 0) liefern keine Information für das Modell.
Q15 Nenne die drei Kategorien von Feature-Selection-Methoden.
Filter: Statistisches Maß unabhängig vom Modell (VarianceThreshold, SelectKBest)
Wrapper: Modell wird mit verschiedenen Subsets trainiert (RFE)
Embedded: Selection während des Trainings (Lasso/L1, Feature Importance)
Q16 Was misst f_classif in SelectKBest?
Den ANOVA F-Wert — wie stark ein Feature zwischen den Klassen unterscheidet (lineare Abhängigkeit). Hoher F-Wert = Feature trennt Klassen gut.
Q17 Nenne 3 Gründe warum zu viele Features schaden.
1. Overfitting: Modell lernt Rauschen
2. Fluch der Dimensionalität: Abstände verlieren Bedeutung in hohen Dimensionen
3. Rechenzeit: Mehr Berechnungen
(+ Interpretierbarkeit, Speicher)
Q18 Prüfungsfrage: Was ist "Data Leakage" und wie entsteht es?
Data Leakage bedeutet, dass Information aus dem Test-Set in das Training "einsickert". Entsteht durch: Scaler auf ganzen Datensatz fitten, Feature Selection auf ganzen Datensatz, Target-basierte Features ohne CV. Folge: Validierungsmetriken sind zu optimistisch — das Modell versagt in der Produktion.
Q19 Erkläre den Unterschied: fit_transform(X_train) vs. transform(X_test)
fit_transform(X_train): Berechnet Parameter (μ, σ oder min, max) aus X_train UND transformiert.
transform(X_test): Nutzt die bereits gelernten Parameter und transformiert nur — OHNE neue Parameter zu berechnen.
So stellt man sicher, dass beide Sets mit denselben Parametern transformiert werden.
Q20 Welcher Vorteil hat eine sklearn Pipeline für Feature Selection + Training?
Die Pipeline handhabt fit/transform automatisch korrekt: Bei pipe.fit(X_train) werden alle Schritte sequenziell auf Train-Daten gefittet. Bei pipe.predict(X_test) oder pipe.score(X_test) wird nur transform() aufgerufen. Data Leakage ist strukturell ausgeschlossen.
