🚀 GaussianMixture sklearn

GMM professionell anwenden: BIC/AIC zur Modellwahl, verschiedene Kovarianz-Typen, Dichte-Schätzung und generative Nutzung.

Stufe 1

🎯 Ziel & Kontext

GMM jenseits von Clustering

  • Density Estimation: GMM schätzt die Wahrscheinlichkeitsdichte p(x) — gut für Anomalie-Detektion
  • Generatives Modell: Neue Datenpunkte aus der gelernten Verteilung samplen
  • Soft Clustering: Überlappende Cluster mit Unsicherheits-Quantifizierung
vs. k-Means: GMM ist k-Means mit weichen Zuweisungen und variablen Cluster-Formen. Wenn covariance_type='spherical' und alle Cluster gleich groß, verhält sich GMM ähnlich wie k-Means.
Stufe 2

🧠 BIC, AIC und Modellwahl

Wie viele Komponenten K?

Im Gegensatz zu k-Means hat GMM Informationskriterien zur Modellwahl:

BIC = −2·log L + p·log(n) (straft mehr Parameter stärker)
AIC = −2·log L + 2·p (weniger Bestrafung)

Kleineres BIC/AIC = besser. p = Anzahl der Modellparameter.

Parameter pro Kovarianz-Typ (d Dimensionen)

covariance_typeParameter pro KomponenteFlexibilität
fulld(d+1)/2Höchste
tiedd(d+1)/2 (geteilt)Mittel
diagdMittel
spherical1Niedrigste
Mit zu vielen Komponenten: Overfitting — eine Komponente "kollabiert" auf einen einzelnen Punkt (Singulärkovarianz). BIC bestraft das automatisch.

⚙️ Workflow: GMM anwenden

1
K via BIC/AIC suchen

GMM für K=1..Kmax anpassen, BIC berechnen. Minimum = bestes K.

2
Kovarianz-Typ wählen

Mit n_init≥5 und Vergleich von covariance_types ausprobieren.

3
Soft Clustering / Density

predict_proba() für Zugehörigkeiten, score_samples() für log-Dichte pro Punkt.

4
Anomalie-Detektion

Punkte mit sehr niedriger score_samples() = Ausreißer.

Stufe 4

🛠️ BIC-Suche von Scratch

🐍 1/2a — Funktionen: compute_bic_scratch & gmm_n_params
import numpy as np

def compute_bic_scratch(log_likelihood, n_params, n_samples):
    """BIC = -2*logL + p*log(n)"""
    return -2 * log_likelihood + n_params * np.log(n_samples)

def gmm_n_params(K, d, covariance_type):
    """Anzahl freier Parameter eines GMM."""
    # Mischungsgewichte: K-1
    # Mittelwerte: K*d
    # Kovarianzen: je nach Typ
    pi_params = K - 1
    mu_params = K * d
    if covariance_type == 'full':
        cov_params = K * d * (d + 1) // 2
    elif covariance_type == 'tied':
        cov_params = d * (d + 1) // 2
    elif covariance_type == 'diag':
        cov_params = K * d
    else:  # spherical
        cov_params = K
    return pi_params + mu_params + cov_params

Test: BIC für K=1..6 selbst berechnen und mit gmm.bic(X) aus sklearn vergleichen:

🐍 1/2b — Test: BIC scratch vs. sklearn
from sklearn.mixture import GaussianMixture

# Test-Daten: 3 Cluster
np.random.seed(42)
X = np.vstack([
    np.random.multivariate_normal([0,0], np.eye(2), 100),
    np.random.multivariate_normal([5,5], [[2,.5],[.5,1]], 80),
    np.random.multivariate_normal([-3,4], np.eye(2)*0.5, 60),
])
n, d = X.shape

print(f"{'K':>4} | {'BIC (scratch)':>15} | {'BIC (sklearn)':>15}")
print("-" * 42)
bics_scratch = []
for K in range(1, 7):
    gmm = GaussianMixture(
        n_components=K,
        covariance_type='full',
        n_init=5,
        random_state=42
    )
    gmm.fit(X)
    ll = gmm.score(X) * n
    p  = gmm_n_params(K, d, 'full')
    bic_s = compute_bic_scratch(ll, p, n)
    bics_scratch.append(bic_s)
    print(f"{K:>4} | {bic_s:>15.1f} | {gmm.bic(X):>15.1f}")

📊 Visualisierung — BIC-Kurve über K

Die BIC-Werte über K aufgetragen ergeben eine U-förmige Kurve: BIC sinkt von K=1 bis K=3 stark (mehr Komponenten erklären die Daten viel besser), erreicht bei K=3 ein Minimum (die wahre Anzahl Cluster), und steigt danach wieder an — zusätzliche Komponenten werden durch den Strafterm p·log(n) bestraft, ohne die Log-Likelihood noch deutlich zu verbessern. Das Minimum der Kurve markiert das beste K (hier K=3).

Stufe 5

🚀 GMM vollständig: Clustering + Anomalie + Generierung

🐍 Schritt 1 — Daten laden & skalieren
from sklearn.mixture import GaussianMixture
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import load_iris
import numpy as np

X, y_true = load_iris(return_X_y=True)
scaler = StandardScaler()
X_s = scaler.fit_transform(X)

print(f"X_s: {X_s.shape}")
▶ Ausgabe
X_s: (150, 4)
🐍 Schritt 2 — Bestes K via BIC suchen
bics = []
for K in range(1, 8):
    g = GaussianMixture(
        n_components=K,
        covariance_type='full',
        n_init=10,
        random_state=42
    )
    bics.append(g.fit(X_s).bic(X_s))

best_K = np.argmin(bics) + 1
print(f"Bestes K (BIC): {best_K}")
▶ Ausgabe
Bestes K (BIC): 2
🐍 Schritt 3 — Finales Modell trainieren
gmm = GaussianMixture(
    n_components=best_K,
    covariance_type='full',
    n_init=10,
    reg_covar=1e-6,
    random_state=42
)
gmm.fit(X_s)

print(f"Modell mit K={best_K} trainiert")
▶ Ausgabe
Modell mit K=2 trainiert
🐍 Schritt 4 — Soft Clustering
probs = gmm.predict_proba(X_s)
labels = gmm.predict(X_s)

print(f"Gelernte Mischungsgewichte: {gmm.weights_.round(3)}")
print(f"Mittlere Unsicherheit:      {(1 - probs.max(axis=1)).mean():.4f}")
▶ Ausgabe
Gelernte Mischungsgewichte: [0.667 0.333]
Mittlere Unsicherheit:      0.0000
🐍 Schritt 5 — Anomalie-Detektion
log_dens = gmm.score_samples(X_s)   # log p(x) für jeden Punkt
threshold = np.percentile(log_dens, 5)  # 5%-Quantil
anomalies = log_dens < threshold

print(f"Anomalien (5%-Quantil): {anomalies.sum()} Punkte")

Anomalien (5%-Quantil): 8 Punkte
🐍 Schritt 6 — Neue Daten generieren
X_gen, labels_gen = gmm.sample(50)
X_gen_orig = scaler.inverse_transform(X_gen)

print(f"Generierte Punkte (Original-Skala): {X_gen_orig.shape}")
print(f"Generiert aus Komponente 0: {(labels_gen==0).sum()} Punkte")

🐍 Plot-Code — Ergebnis: GMM-Cluster mit Soft Assignments (PCA)
# baut auf der vorherigen Zelle auf (X_s, gmm, probs, anomalies)
import matplotlib.pyplot as plt
import numpy as np
from sklearn.decomposition import PCA

pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_s)

fig, ax = plt.subplots(figsize=(6, 5))
sc = ax.scatter(X_pca[:, 0], X_pca[:, 1], c=probs[:, 0], cmap='coolwarm',

ax.scatter(X_pca[anomalies, 0], X_pca[anomalies, 1], facecolors='none',
           edgecolors='lime', s=120, linewidths=2, label='Anomalien')

means_pca = pca.transform(gmm.means_)
ax.scatter(means_pca[:, 0], means_pca[:, 1], c='black', marker='X', s=120, label='Zentren')

fig.colorbar(sc, ax=ax, label='Responsibility Komponente 0')
ax.set_title("GMM-Cluster mit Soft Assignments (PCA)")
ax.set_xlabel("PC1"); ax.set_ylabel("PC2")
ax.legend()
plt.tight_layout()

📊 Visualisierung — GMM-Cluster mit Soft Assignments

Die Projektion der 4 Iris-Features per PCA auf 2 Dimensionen zeigt, wie die Punkte je nach predict_proba eingefärbt sind — Punkte tief im Inneren eines Clusters haben eine Zuweisung nahe 1.0, Punkte zwischen den beiden Clustern eine gemischte Farbe (hohe Unsicherheit). Die mit grünen Ringen markierten Punkte sind die Anomalien mit sehr niedrigem score_samples-Wert (aus Schritt 5) — sie liegen meist am Rand der Punktwolke, abseits der Cluster-Zentren.
