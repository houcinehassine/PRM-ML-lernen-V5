⚙️ E-Step & M-Step

Die zwei Herzstücke des EM-Algorithmus im Detail: Responsibilities berechnen und Parameter analytisch aktualisieren.

Stufe 1

🎯 Ziel & Kontext

Warum zwei getrennte Schritte?

Das direkte Optimieren von log p(X|θ) ist schwierig. EM teilt das Problem:

  • E-Schritt: Was ist die wahrscheinlichste Zugehörigkeit unter aktuellen Parametern? → Responsibilities r
  • M-Schritt: Was sind die besten Parameter für diese Zugehörigkeiten? → analytische Lösung!
Prüfungspunkt: Die M-Schritt-Updates sind analytisch — es gibt keine Gradientenabstieg-Iteration, weil die Zielfunktion in geschlossener Form lösbar ist.
Stufe 2

🧠 Mathematik beider Schritte

E-Schritt: Posterior-Berechnung

Gegeben θ = {π, μ, Σ}: Wie wahrscheinlich ist, dass xᵢ aus Komponente k kam? (Bayes-Theorem)

rᵢₖ = P(zᵢ=k | xᵢ, θ) = πₖ N(xᵢ; μₖ, Σₖ) / Σⱼ πⱼ N(xᵢ; μⱼ, Σⱼ)

Das ist die posterior Wahrscheinlichkeit der Komponentenzugehörigkeit.

M-Schritt: Parameter-Update

Gegeben r: Maximiere Q(θ) = Σᵢ Σₖ rᵢₖ log[πₖ N(xᵢ; μₖ, Σₖ)]

Effektive Größe:
Nₖ = Σᵢ rᵢₖ

Mischungsgewichte:
πₖ* = Nₖ / N

Mittelwert (gewichtetes Mittel):
μₖ* = (1/Nₖ) Σᵢ rᵢₖ xᵢ

Kovarianz (gewichtete Kovarianz):
Σₖ* = (1/Nₖ) Σᵢ rᵢₖ (xᵢ−μₖ*)(xᵢ−μₖ*)ᵀ

Diese Formeln sind die analytischen Maxima — keine Iteration im M-Schritt nötig!

Stufe 3

⚙️ Numerische Stabilität

Log-Sum-Exp Trick

Im E-Schritt können Wahrscheinlichkeiten wie N(xᵢ; μₖ, Σₖ) extrem klein werden (Underflow). Die Lösung: in Log-Space rechnen.

1
Log-Gewichte berechnen:

log_rᵢₖ = log(πₖ) + log N(xᵢ; μₖ, Σₖ)

2
Log-Sum-Exp Trick:

max_k = max_k(log_rᵢₖ)
log_sumₖ = max_k + log Σₖ exp(log_rᵢₖ − max_k)

3
Normalisieren:

log rᵢₖ_norm = log_rᵢₖ − log_sumₖ
rᵢₖ = exp(log rᵢₖ_norm)

Singularität: Wenn eine Komponente nur auf einem Punkt liegt (Nₖ=1), wird Σₖ singulär. Lösung: regularisieren mit Σₖ += ε·I (reg_covar in sklearn).
Stufe 4

🛠️ E-Step & M-Step isoliert

🐍 E-Step — Responsibilities berechnen
import numpy as np
from scipy.stats import multivariate_normal
from scipy.special import logsumexp

def e_step(X, pi, mu, sigma):
    """E-Schritt: Responsibilities berechnen (numerisch stabil)."""
    n, K = len(X), len(pi)
    log_R = np.zeros((n, K))

    for k in range(K):
        log_R[:, k] = np.log(pi[k] + 1e-300) + multivariate_normal.logpdf(
            X, mean=mu[k], cov=sigma[k])

    # Log-Sum-Exp normalisieren
    log_sum = logsumexp(log_R, axis=1, keepdims=True)  # (n,1)
    R = np.exp(log_R - log_sum)

    # Log-Likelihood
    ll = log_sum.sum()
    return R, ll

🐍 M-Step — Parameter analytisch aktualisieren
def m_step(X, R):
    """M-Schritt: Parameter analytisch aktualisieren."""
    n, K = R.shape
    d = X.shape[1]
    Nk = R.sum(axis=0)   # (K,)

    pi_new = Nk / n
    mu_new = np.zeros((K, d))
    sigma_new = []

    for k in range(K):
        mu_new[k] = (R[:, k:k+1] * X).sum(axis=0) / Nk[k]
        diff = X - mu_new[k]   # (n, d)
        Sk = (R[:, k] * diff.T) @ diff / Nk[k]  # (d, d)
        Sk += 1e-6 * np.eye(d)  # Regularisierung
        sigma_new.append(Sk)

    return pi_new, mu_new, sigma_new

Jetzt die volle EM-Schleife: e_step und m_step abwechselnd aufrufen, bis die Log-Likelihood konvergiert:

🐍 Iterations-Loop — e_step + m_step bis Konvergenz
lls = []
for it in range(50):
    R, ll = e_step(X, pi, mu, sig)
    pi, mu, sig = m_step(X, R)
    lls.append(ll)
    if it > 0 and abs(lls[-1] - lls[-2]) < 1e-6:
        print(f"Konvergiert nach {it+1} Iterationen")
        break

print(f"Finale Log-Likelihood: {lls[-1]:.2f}")
print(f"Gelernte Mittelwerte:\n{mu}")
print(f"Gelernte Gewichte: {pi}")

E-Step

Berechnet R (Responsibilities) bei festen Parametern θ — eine reine Bayes'sche Posterior-Berechnung, keine Optimierung.

↔
M-Step

Berechnet neue Parameter θ bei festen Responsibilities R — analytische geschlossene Lösung (gewichtete Mittelwerte/Kovarianzen), kein Gradientenabstieg.

🚀 Konvergenz & Diagnose

🐍 Schritt 1 — GaussianMixture mit verbose fitten
from sklearn.mixture import GaussianMixture
import numpy as np

np.random.seed(42)
X1 = np.random.multivariate_normal([0,0], [[1,.5],[.5,1]], 100)
X2 = np.random.multivariate_normal([5,2], [[1,0],[0,1]], 80)
X  = np.vstack([X1, X2])

# verbose für Konvergenz-Beobachtung
gmm = GaussianMixture(
    n_components=2,
    covariance_type='full',
    max_iter=200,
    tol=1e-6,
    n_init=1,
    random_state=42,
    verbose=2
)
gmm.fit(X)

print(f"\nKonvergiert: {gmm.converged_}")
print(f"Iterationen: {gmm.n_iter_}")
print(f"Log-Likelihood: {gmm.lower_bound_:.4f}")
