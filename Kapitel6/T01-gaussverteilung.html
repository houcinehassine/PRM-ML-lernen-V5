🔔 Gaußverteilung

Das Fundament von GMM: Die Normal- und multivariate Gaußverteilung — von der 1D-Glockenkurve zur vollen Kovarianzmatrix.

Stufe 1

🎯 Ziel & Kontext

Warum die Gaußverteilung so zentral ist

  • Zentraler Grenzwertsatz: Summen vieler unabhängiger Variablen konvergieren zur Gaußverteilung
  • Nur 2 Parameter (μ, σ²) beschreiben sie vollständig
  • GMM = Gaussian Mixture Model — eine Mischung aus mehreren Gaußverteilungen
Intuition: Statt k-Means (harte Zuweisung — ein Punkt gehört zu genau einem Cluster) arbeitet GMM mit weichen Wahrscheinlichkeiten: "Punkt A gehört zu 80% Cluster 1 und zu 20% Cluster 2."
Stufe 2

🧠 Univariate & Multivariate Gaußverteilung

Univariat (1D)

N(x; μ, σ²) = (1/√(2πσ²)) · exp(−(x−μ)²/(2σ²))
  • μ = Erwartungswert (Mittelwert / Zentrum der Glockenkurve)
  • σ² = Varianz (Breite der Kurve)
  • Fläche unter der Kurve = 1 (Wahrscheinlichkeitsdichte)

Multivariat (D-dimensional)

N(x; μ, Σ) = (1/((2π)^(D/2)|Σ|^(1/2))) · exp(−½(x−μ)ᵀ Σ⁻¹ (x−μ))
  • μ ∈ ℝᴰ = Mittelwert-Vektor
  • Σ ∈ ℝᴰˣᴰ = Kovarianz-Matrix (symmetrisch, positiv-definit)
  • (x−μ)ᵀ Σ⁻¹ (x−μ) = Mahalanobis-Distanz (elliptische Konturlinien)

Kovarianz-Matrix-Typen

Stufe 3

⚙️ Gaussian Mixture Model

GMM nimmt an, dass die Daten aus K Gaußverteilungen entstanden sind:

p(x) = Σₖ πₖ · N(x; μₖ, Σₖ)

πₖ = Mischungsgewicht (mixing coefficient), Σₖ πₖ = 1
μₖ = Mittelwert der k-ten Komponente
Σₖ = Kovarianz der k-ten Komponente
1
Modell-Annahme: Jeder Datenpunkt wurde zufällig aus einer der K Komponenten gezogen — wir wissen nicht welcher (latente Variable z).
2
Ziel: Parameter {πₖ, μₖ, Σₖ} finden, die die Log-Likelihood log p(X|θ) = Σᵢ log p(xᵢ|θ) maximieren.
3
Problem: Direkte Maximierung schwierig wegen des Σₖ im Logarithmus → EM-Algorithmus!
Stufe 4

🛠️ Von Scratch: Gaußverteilung

🐍 1/3a — Funktionen: gaussian_pdf_1d & gaussian_pdf_nd
import numpy as np

def gaussian_pdf_1d(x, mu, sigma2):
    """Univariate Gaußverteilung Wahrscheinlichkeitsdichte."""
    return (1 / np.sqrt(2 * np.pi * sigma2)) * np.exp(-(x - mu)**2 / (2 * sigma2))

def gaussian_pdf_nd(X, mu, Sigma):
    """Multivariate Gaußverteilung Wahrscheinlichkeitsdichte.
    X: (n, d), mu: (d,), Sigma: (d, d)
    Returns: (n,) array of densities
    """
    d = len(mu)
    diff = X - mu                              # (n, d)
    Sigma_inv = np.linalg.inv(Sigma)
    det = np.linalg.det(Sigma)

    # Mahalanobis-Distanz für alle Punkte gleichzeitig
    mahal = np.einsum('ij,jk,ik->i', diff, Sigma_inv, diff)  # (n,)

    coeff = 1 / ((2 * np.pi) ** (d / 2) * np.sqrt(det))
    return coeff * np.exp(-0.5 * mahal)

📊 Visualisierung — Gaußverteilung in 1D und 2D

Die 1D-PDF gaussian_pdf_1d ergibt die bekannte Glockenkurve mit Maximum bei μ und abfallenden Flanken, deren Breite durch σ² bestimmt wird. Die 2D-PDF gaussian_pdf_nd erzeugt elliptische Konturlinien (Höhenlinien gleicher Dichte) — die Form und Orientierung der Ellipse wird durch die Kovarianzmatrix Σ festgelegt: Diagonaleinträge bestimmen die Breite entlang der Achsen, Nicht-Diagonal- einträge die Rotation/Korrelation.

Stufe 5

🚀 Gaußverteilung mit scipy & numpy

🐍 Schritt 1 — Zwei Gaußkomponenten & Daten ziehen
import numpy as np
from scipy.stats import multivariate_normal

# Zwei 2D-Gaußverteilungen (wie in GMM)
comp1 = multivariate_normal(mean=[0, 0], cov=[[1, 0.5],[0.5, 1]])
comp2 = multivariate_normal(mean=[4, 2], cov=[[1.5, -0.3],[-0.3, 0.8]])

# Daten aus Mischung ziehen
np.random.seed(42)
n1, n2 = 150, 100
X1 = comp1.rvs(n1)
X2 = comp2.rvs(n2)
X  = np.vstack([X1, X2])
y_true = np.array([0]*n1 + [1]*n2)

print(f"X: {X.shape}, Klasse 0: {n1}, Klasse 1: {n2}")
▶ Ausgabe
X: (250, 2), Klasse 0: 150, Klasse 1: 100
🐍 Schritt 2 — PDF-Werte & Responsibilities berechnen
# PDF-Werte für alle Punkte berechnen
p1 = comp1.pdf(X)  # P(X | Komponente 1)
p2 = comp2.pdf(X)  # P(X | Komponente 2)

# Weiche Zuweisung (Responsibilities) mit Mischungsgewichten 0.6 / 0.4
pi1, pi2 = 0.6, 0.4
r1 = pi1 * p1 / (pi1 * p1 + pi2 * p2)  # P(Komponente 1 | X)
r2 = 1 - r1

print(f"Durchschnittliche Responsibility r1: {r1.mean():.3f} (erwartet: ~0.6)")
▶ Ausgabe
Durchschnittliche Responsibility r1: 0.603 (erwartet: ~0.6)
🐍 Schritt 3 — Harte Zuweisung & Genauigkeit
labels_pred = (r1 < 0.5).astype(int)  # harte Zuweisung aus weicher
accuracy = np.mean(labels_pred == y_true)
print(f"Genauigkeit mit wahren Parametern: {accuracy:.2%}")
▶ Ausgabe
Genauigkeit mit wahren Parametern: 97.60%
Harte Zuweisung (k-Means-Stil)

Jeder Punkt gehört zu genau einem Cluster: labels_pred = (r1 < 0.5). Information über Unsicherheit nahe der Cluster-Grenze geht verloren.

↔
Weiche Zuweisung (GMM-Responsibility)

Jeder Punkt erhält ein Wahrscheinlichkeits-Paar (r1, r2), z.B. (0.8, 0.2). Punkte in Überlappungszonen behalten ihre Unsicherheit — wichtig für Dichte-Schätzung und Anomalie-Detektion.
