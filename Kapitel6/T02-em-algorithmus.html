🔄 EM-Algorithmus

Expectation-Maximization: Das allgemeine Framework für latente-Variable-Modelle — iterativ bis zur Konvergenz.

Stufe 1

🎯 Ziel & Kontext

Das Problem mit latenten Variablen

Viele Modelle haben latente (verborgene) Variablen. Bei GMM: wir sehen die Datenpunkte X, aber nicht aus welcher Gaußkomponente sie kamen (z = Komponentenzugehörigkeit).

Henne-Ei-Problem: Wenn wir wüssten, welcher Punkt zu welcher Komponente gehört, könnten wir die Parameter schätzen. Wenn wir die Parameter kennen, könnten wir die Zugehörigkeiten bestimmen. EM löst das durch Iteration.
Garantie: Jede EM-Iteration erhöht (oder hält gleich) die Log-Likelihood. EM konvergiert — aber möglicherweise zu einem lokalen Maximum!
Stufe 2

🧠 ELBO & die zwei Schritte

Ziel: Log-Likelihood maximieren

log p(X|θ) = Σᵢ log Σₖ πₖ N(xᵢ|μₖ,Σₖ)

Das log-of-sum ist analytisch schwer zu maximieren. EM nutzt die Evidence Lower BOund (ELBO):

log p(X|θ) ≥ ELBO = Σᵢ Σₖ rᵢₖ log[πₖ N(xᵢ|μₖ,Σₖ)] + H(r)

wobei rᵢₖ = Responsibility (weiche Zuweisung von Punkt i zu Komponente k).

Die zwei Schritte

SchrittAktionWas wird optimiert?
E-Schrittrᵢₖ berechnen (Responsibilities)ELBO über q(z) = posterior p(z|X,θ)
M-Schrittθ = {π,μ,Σ} aktualisierenELBO über θ, mit festen rᵢₖ

Konvergenz

  • Monotone Verbesserung: ELBO(t+1) ≥ ELBO(t) garantiert
  • Konvergenz zu lokalem Maximum (nicht globalem)
  • Mehrere zufällige Startpunkte (n_init) nötig
  • Konvergenzkritierium: |ELBO(t) − ELBO(t−1)| < tol
Stufe 3

⚙️ EM Schritt für Schritt

0
Initialisierung

Wähle zufällige {πₖ, μₖ, Σₖ} für k=1..K. Oft: k-Means zur Initialisierung der μₖ (stabiler).

E
E-Schritt: Responsibilities berechnen

rᵢₖ = πₖ N(xᵢ|μₖ,Σₖ) / Σⱼ πⱼ N(xᵢ|μⱼ,Σⱼ)

rᵢₖ ∈ [0,1] und Σₖ rᵢₖ = 1 für jeden Punkt i.

M
M-Schritt: Parameter aktualisieren

Nₖ = Σᵢ rᵢₖ (effektive Punktanzahl)
πₖ = Nₖ/N
μₖ = (1/Nₖ) Σᵢ rᵢₖ xᵢ
Σₖ = (1/Nₖ) Σᵢ rᵢₖ (xᵢ−μₖ)(xᵢ−μₖ)ᵀ

∞
Konvergenz prüfen

Log-Likelihood berechnen. Wenn Änderung < tol → Stop. Sonst → zurück zu E-Schritt.

Stufe 4

🛠️ EM von Scratch (GMM)

🐍 1/2a — Klasse: GMMScratch
import numpy as np
from scipy.stats import multivariate_normal
from sklearn.cluster import KMeans

class GMMScratch:
    """GMM via EM-Algorithmus."""

    def __init__(self, K=2, max_iter=200, tol=1e-6, random_state=42):
        self.K = K
        self.max_iter = max_iter
        self.tol = tol
        self.rng = np.random.default_rng(random_state)

    def fit(self, X):
        n, d = X.shape
        K = self.K

        # Initialisierung per k-Means
        km = KMeans(K, n_init=3, random_state=42).fit(X)
        self.mu_ = km.cluster_centers_.copy()
        self.sigma_ = [np.eye(d) for _ in range(K)]
        self.pi_ = np.full(K, 1/K)

        self.log_likelihoods_ = []

        for it in range(self.max_iter):
            # ─── E-Step: Responsibilities ───────────────────
            R = np.zeros((n, K))
            for k in range(K):
                R[:, k] = self.pi_[k] * multivariate_normal.pdf(
                    X, mean=self.mu_[k], cov=self.sigma_[k])
            R_sum = R.sum(axis=1, keepdims=True)
            R /= R_sum          # normalisieren → rᵢₖ ∈ [0,1]

            # Log-Likelihood berechnen
            ll = np.log(R_sum).sum()
            self.log_likelihoods_.append(ll)

            # ─── M-Step: Parameter aktualisieren ────────────
            Nk = R.sum(axis=0)   # effektive Punktanzahl pro Komponente

            for k in range(K):
                self.mu_[k] = (R[:, k:k+1] * X).sum(axis=0) / Nk[k]
                diff = X - self.mu_[k]
                self.sigma_[k] = (R[:, k] * diff.T @ diff) / Nk[k]
                # Numerische Stabilität: kleine Diagonale
                self.sigma_[k] += 1e-6 * np.eye(d)
            self.pi_ = Nk / n

            # Konvergenz?
            if it > 0 and abs(self.log_likelihoods_[-1] - self.log_likelihoods_[-2]) < self.tol:
                print(f"Konvergiert nach {it+1} Iterationen")
                break

        return self

    def predict_proba(self, X):
        """Weiche Zuweisung (Responsibilities)."""
        n, K = len(X), self.K
        R = np.zeros((n, K))
        for k in range(K):
            R[:, k] = self.pi_[k] * multivariate_normal.pdf(
                X, mean=self.mu_[k], cov=self.sigma_[k])
        return R / R.sum(axis=1, keepdims=True)

    def predict(self, X):
        return self.predict_proba(X).argmax(axis=1)

Test auf synthetischen Daten mit zwei klar getrennten Clustern:

🐍 1/2b — Test: GMMScratch
from scipy.optimize import linear_sum_assignment
from sklearn.metrics import confusion_matrix

np.random.seed(42)
X1 = np.random.multivariate_normal([0, 0], [[1, .5],[.5, 1]], 100)
X2 = np.random.multivariate_normal([5, 2], [[1, -.3],[-.3, .8]], 80)
X  = np.vstack([X1, X2])
y_true = np.array([0]*100 + [1]*80)

gmm = GMMScratch(K=2)
gmm.fit(X)
labels = gmm.predict(X)

# Accuracy (Label-Matching nötig, da Cluster-IDs beliebig)
cm = confusion_matrix(y_true, labels)
row, col = linear_sum_assignment(-cm)
acc = cm[row, col].sum() / len(y_true)
print(f"Genauigkeit: {acc:.2%}")
print(f"Gelernte Mittelwerte: {gmm.mu_}")

Die Kurve von gmm.log_likelihoods_ über die Iterationen zeigt eine monoton steigende Kurve, die sich nach wenigen Iterationen abflacht — das ist die EM-Konvergenzgarantie in Aktion: jede Iteration verbessert (oder hält) die Log-Likelihood, bis die Änderung unter tol fällt und der Algorithmus stoppt.

🚀 GMM mit sklearn

🐍 Schritt 1 — Daten & GaussianMixture fitten
from sklearn.mixture import GaussianMixture
import numpy as np

# Daten
np.random.seed(42)
X1 = np.random.multivariate_normal([0, 0], [[1,.5],[.5,1]], 100)
X2 = np.random.multivariate_normal([5, 2], [[1,-.3],[-.3,.8]], 80)
X  = np.vstack([X1, X2])

# GaussianMixture mit n_init für Robustheit
gmm = GaussianMixture(
    n_components=2,
    covariance_type='full',
    n_init=10,
    random_state=42
)
gmm.fit(X)

print("Gelernte Mittelwerte:")
print(gmm.means_)
print("\nLog-Likelihood:", gmm.score(X))
