⚖️ Bias-Variance Tradeoff

Warum ist der Fehler eines ML-Modells in zwei Komponenten zerlegbar — und warum kann man nicht beides gleichzeitig minimieren?

Stufe 1

🎯 Ziel & Kontext

Die Dartscheiben-Analogie

Stell dir vier Schützen vor, die auf eine Dartscheibe zielen. Das Zentrum ist der "wahre" Wert:

🎯

Low Bias, Low Variance

Alle Würfe nah am Zentrum, eng beieinander. Ideal!

↗️🎯

High Bias, Low Variance

Konsistent daneben — immer am selben falschen Ort. Underfitting.

💫

Low Bias, High Variance

Im Schnitt richtig, aber sehr streuen. Overfitting.

🌪️

High Bias, High Variance

Daneben UND überall verstreut. Schlimmstes Szenario.

Das Dilemma: Erhöht man die Modellkomplexität, sinkt Bias — aber Variance steigt. Verringert man Komplexität, sinkt Variance — aber Bias steigt. Man kann nicht beide gleichzeitig minimieren.
Stufe 2

🧠 Theorie: Die Fehlerzerlegung

Mathematische Zerlegung

Der Expected Prediction Error (erwarteter Vorhersagefehler) zerfällt in drei Teile:

E[(y − ŷ)²] = Bias² + Variance + Irreducible Noise
KomponenteWas es istVerringerbar?
Bias² Systematischer Fehler — das Modell liegt im Schnitt daneben, weil es zu simpel ist ✅ Durch komplexeres Modell
Variance Wie stark reagiert das Modell auf kleine Änderungen in den Trainingsdaten? ✅ Durch Regularisierung / mehr Daten
Irreducible Noise Zufälliges Rauschen in den Daten — kann kein Modell eliminieren ❌ Nie

Bias und Variance in Abhängigkeit von Modellkomplexität

Niedriger Komplexität (z.B. lineares Modell):
→ Bias hoch (kann komplexe Muster nicht lernen)
→ Variance niedrig (reagiert kaum auf Datenschwankungen)

Hoher Komplexität (z.B. tiefer Entscheidungsbaum):
→ Bias niedrig (kann fast alles lernen)
→ Variance hoch (kleine Änderungen in Trainingsdaten → stark anderes Modell)

Der Sweet Spot: Dort wo Bias² + Variance minimal ist.
📏 Niedrige Komplexität

z.B. lineares Modell. Bias hoch (kann komplexe Muster nicht abbilden), Variance niedrig (reagiert kaum auf Datenschwankungen).

↔
🌳 Hohe Komplexität

z.B. tiefer Entscheidungsbaum. Bias niedrig (kann fast alles lernen), Variance hoch (kleine Änderungen in Trainingsdaten → stark anderes Modell).

Praktische Implikationen

ProblemHauptursacheLösung
Modell generalisiert schlecht (Train ≈ Test, beide schlecht) High Bias Komplexeres Modell, mehr Features, weniger Regularisierung
Modell generalisiert schlecht (Train gut, Test schlecht) High Variance Regularisierung, mehr Daten, Ensemble-Methoden
Ensemble (Random Forest) reduziert Variance — Viele verschiedene Modelle → Variance mittelt sich raus
🔗 Querverweis

Wie Bagging die Variance konkret reduziert, siehe K5-T03 · Random Forest.

Stufe 3

⚙️ Bias und Variance empirisch schätzen

Man kann Bias und Variance empirisch schätzen, indem man dasselbe Modell auf vielen verschiedenen Trainingsdatensätzen trainiert:

1
B Bootstrap-Stichproben aus den Daten ziehen

Jede Stichprobe ist ein anderes "Trainingsszenario".

2
Modell auf jeder Stichprobe trainieren

Man erhält B verschiedene Modelle f₁, f₂, ..., f_B.

3
Bias schätzen

Bias = (Mittelwert aller Vorhersagen) − wahrer Wert

4
Variance schätzen

Variance = Varianz der B Vorhersagen am selben Punkt

Stufe 4

🛠️ Von Scratch: Bias-Variance schätzen

🐍 1/2a — Funktion: bias_variance_decomp 
import numpy as np

def bias_variance_decomp(model_class, X, y, test_x, true_y,
                          n_bootstrap=200, **model_kwargs):
    """
    Schätzt Bias² und Variance eines Modells durch Bootstrapping.
    model_class: sklearn-kompatible Klasse
    test_x: einzelner Testpunkt (1D Array)
    true_y: wahrer Wert an test_x
    """
    predictions = []
    n = len(X)

    for _ in range(n_bootstrap):
        # Bootstrap-Stichprobe (mit Zurücklegen)
        idx = np.random.choice(n, n, replace=True)
        X_boot, y_boot = X[idx], y[idx]

        # Modell trainieren
        m = model_class(**model_kwargs)
        m.fit(X_boot.reshape(-1,1), y_boot)

        # Vorhersage am Testpunkt
        pred = m.predict(test_x.reshape(1,-1))[0]
        predictions.append(pred)

    predictions = np.array(predictions)
    mean_pred = predictions.mean()

    bias_sq = (mean_pred - true_y) ** 2
    variance = predictions.var()
    mse      = bias_sq + variance  # (ohne irred. Noise)

    return bias_sq, variance, mse

Jetzt vergleichen wir Lineare Regression mit Decision Trees unterschiedlicher Tiefe auf Daten y = x³ + Rauschen:

🐍 1/2b — Test: Modelle vergleichen 
from sklearn.linear_model import LinearRegression
from sklearn.tree import DecisionTreeRegressor

np.random.seed(42)
X = np.linspace(-2, 2, 80)
y = X**3 + np.random.normal(0, 1.5, 80)

test_x = np.array([1.0])
true_y = 1.0**3  # = 1.0

print("Modell             | Bias²   | Variance | MSE")
print("-" * 52)
for name, cls, kwargs in [
    ("Lineare Regression",  LinearRegression,    {}),
    ("Tree depth=2",        DecisionTreeRegressor, {"max_depth": 2}),
    ("Tree depth=5",        DecisionTreeRegressor, {"max_depth": 5}),
    ("Tree depth=10",       DecisionTreeRegressor, {"max_depth": 10}),
]:
    b2, var, mse = bias_variance_decomp(cls, X, y, test_x, true_y, **kwargs)
    print(f"{name:<20} | {b2:>7.4f} | {var:>8.4f} | {mse:.4f}")

🐍 Plot-Code — Ergebnis: Bias² und Variance je Modell
# baut auf der vorherigen Zelle auf (bias_variance_decomp, X, y, test_x, true_y)
import matplotlib.pyplot as plt

models_info = [

x = np.arange(len(names))
width = 0.35

ax.bar(x - width/2, bias2s, width, label='Bias²', color='#3a7ca5')

ax.set_xticks(x)

ax.legend()

📊 Visualisierung — Bias² und Variance je Modell

Das gruppierte Balkendiagramm zeigt für jedes Modell zwei Balken (Bias² und Variance). Die Lineare Regression hat den höchsten Bias² (1.68, weil eine Gerade die Kubik-Kurve nicht treffen kann) aber die niedrigste Variance (0.08, sehr stabil). Tree depth=5 hat den niedrigsten Bias² (0.03) bei moderater Variance — daher auch das niedrigste MSE (0.68) und der beste Kompromiss. Tree depth=10 ist überraschend instabil (hohe Variance), da einzelne Bootstrap-Stichproben zu sehr unterschiedlichen tiefen Bäumen führen.

Regularisierungsparameter kontrollieren den Tradeoff

🐍 Schritt 2 — Regularisierungsstärke variieren 
from sklearn.linear_model import Ridge
from sklearn.model_selection import cross_val_score
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import Pipeline

alphas = [0.001, 0.01, 0.1, 1.0, 10.0, 100.0]

print(f"{'alpha':>8} | {'CV Mean':>10} | {'CV Std':>8} | Interpretation")
print("-" * 58)
for alpha in alphas:
    pipe = Pipeline([
        ('poly', PolynomialFeatures(degree=5, include_bias=False)),
        ('ridge', Ridge(alpha=alpha))
    ])
    scores = cross_val_score(pipe, X, y, cv=5, scoring='r2')
    if alpha < 0.01:
        interp = "High Var (Overfitting)"
    elif alpha > 10:
        interp = "High Bias (Underfitting)"
    else:
        interp = "✅ Good Balance"
    print(f"{alpha:>8} | {scores.mean():>10.4f} | {scores.std():>8.4f} | {interp}")

🐍 Schritt 3 — Ensemble reduziert Variance 
from sklearn.ensemble import BaggingRegressor
from sklearn.tree import DecisionTreeRegressor

base = DecisionTreeRegressor(max_depth=10)
bag = BaggingRegressor(
    estimator=base,
    n_estimators=50,
    random_state=42
)

for name, m in [("Single Tree (depth=10)", base), ("Bagging 50 Trees", bag)]:
    s = cross_val_score(m, X, y, cv=5, scoring='r2')
    print(f"{name:<24}: mean={s.mean():.4f}, std={s.std():.4f}")

🐍 Plot-Code — Ergebnis: CV-Score vs. alpha (Tradeoff-Kurve)
# baut auf der vorherigen Zelle auf (alphas, X, y)
import matplotlib.pyplot as plt

means, stds = [], []
for alpha in alphas:
    pipe = Pipeline([
        ('poly', PolynomialFeatures(degree=5, include_bias=False)),
        ('ridge', Ridge(alpha=alpha))
    ])
    scores = cross_val_score(pipe, X, y, cv=5, scoring='r2')
    means.append(scores.mean())
    stds.append(scores.std())

fig, ax = plt.subplots(figsize=(5.5, 3.4))
ax.errorbar(alphas, means, yerr=stds, marker='o', color='#2e8b57', capsize=4)
ax.set_xscale('log')
ax.set_xlabel("alpha (log-Skala)")
ax.set_ylabel("CV Mean R² (± Std)")
ax.set_title("CV-Score vs. alpha (Tradeoff-Kurve)")
plt.show()
📊 Visualisierung — CV-Score vs. alpha (Tradeoff-Kurve)

Die Kurve von CV-Mean (R²) gegen alpha (log-Skala) bildet die klassische Tradeoff-Form: bei sehr kleinem alpha ist die Streuung (CV Std) groß — Overfitting. Bei sehr großem alpha (100) sinkt sowohl der Mittelwert als auch die Streuung stark — das Modell ist zu stark eingeschränkt (Underfitting). Der Sweet Spot liegt bei alpha ≈ 0.01–10, wo CV-Mean noch hoch und CV-Std moderat ist. Das Bagging-Ensemble (Schritt 3) zeigt denselben Effekt auf andere Weise: derselbe Baum, aber 50× gemittelt, hat eine deutlich höhere mittlere Performance als ein einzelner Baum.

Train hoch, Test niedrigHigh VarianceMehr Daten, Regularisierung (alpha↑), Ensemble
Hohe CV-StdHigh VarianceBagging, Random Forest, mehr Daten
CV Mean niedrig, Std niedrigHigh BiasExpressive Modelle, Feature Engineering
