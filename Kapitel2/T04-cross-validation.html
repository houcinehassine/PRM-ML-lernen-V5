🔄 Cross-Validation

Warum reicht ein einzelner Train/Test-Split nicht aus — und wie bewertet man ein Modell zuverlässig ohne Testdaten zu "verbrauchen"?

Stufe 1

🎯 Ziel & Kontext

Das Problem mit einem einzelnen Split

Angenommen du teilst deine 100 Datenpunkte 80/20 auf. Dein Modell erreicht 90% auf dem Test-Set. Wie sicher bist du, dass das kein Zufall war?

Das Problem: Mit nur 20 Testpunkten kann die Accuracy stark schwanken — je nach "Glück" beim Split. Du könntest zufällig die "leichten" Punkte im Test-Set haben.

Cross-Validation löst das: Statt einmal zu teilen, wird der Datensatz K-mal anders aufgeteilt und der Fehler wird gemittelt. Das ergibt eine robuste, zuverlässige Schätzung.

Wann brauche ich Cross-Validation?

SituationWas tun
Modellauswahl (welcher Algorithmus?)CV auf Trainingsdaten, bestes Modell wählen
Hyperparameter-TuningGridSearchCV / RandomizedSearchCV
Finale Performance schätzenNested CV oder held-out Test-Set
Kleine DatenmengeLOOCV (jeder Punkt einmal Test)

Stufe 3

⚙️ K-Fold CV Algorithmus

1
Datensatz in K gleiche Teile (Folds) aufteilen

Bei n=100 Punkten und K=5: jeder Fold hat 20 Punkte.

2
Für i = 1 bis K:

Fold i → Test-Set. Alle anderen Folds → Training-Set.

3
Modell auf Train-Folds trainieren, auf Test-Fold evaluieren

Scorei speichern. Modell danach verwerfen.

4
CV-Score = Mittelwert aller K Scores

CV_std gibt an, wie stabil das Modell ist. Kleine Std = konsistentes Modell.

5
Finales Modell auf dem GESAMTEN Datensatz trainieren

Achtung: CV schätzt die Performance — das finale Modell wird auf allen verfügbaren Daten trainiert.

Stufe 4

🛠️ Von Scratch: K-Fold CV

🐍 1/2a — Klasse: KFoldCV 
import numpy as np

class KFoldCV:
    """K-Fold Cross-Validation von Scratch."""

    def __init__(self, k=5, shuffle=True, random_state=None):
        self.k = k
        self.shuffle = shuffle
        self.rng = np.random.default_rng(random_state)

    def split(self, X):
        """Gibt (train_idx, test_idx) Paare zurück."""
        n = len(X)
        indices = np.arange(n)
        if self.shuffle:
            self.rng.shuffle(indices)

        # n in K gleich große Teile aufteilen
        fold_sizes = np.full(self.k, n // self.k)
        fold_sizes[:n % self.k] += 1   # Rest-Punkte verteilen

        splits = []
        current = 0
        for size in fold_sizes:
            test_idx  = indices[current : current + size]
            train_idx = np.concatenate([indices[:current],
                                        indices[current + size:]])
            splits.append((train_idx, test_idx))
            current += size
        return splits

    def cross_val_score(self, model_class, X, y, **model_kwargs):
        """Evaluiert ein Modell mit K-Fold CV."""
        scores = []
        for train_idx, test_idx in self.split(X):
            X_tr, X_te = X[train_idx], X[test_idx]
            y_tr, y_te = y[train_idx], y[test_idx]

            m = model_class(**model_kwargs)
            m.fit(X_tr, y_tr)
            scores.append(m.score(X_te, y_te))
        return np.array(scores)

Erweiterung: Stratified K-Fold erhält die Klassenverteilung in jedem Fold:

🐍 2/2 — Klasse: StratifiedKFoldCV 
class StratifiedKFoldCV:
    """Erhält Klassenverteilung in jedem Fold."""

    def __init__(self, k=5, random_state=None):
        self.k = k
        self.rng = np.random.default_rng(random_state)

    def split(self, X, y):
        n = len(X)
        classes = np.unique(y)
        # Für jede Klasse: Indizes mischen und in K Teile aufteilen
        fold_indices = [[] for _ in range(self.k)]

        for cls in classes:
            cls_idx = np.where(y == cls)[0]
            self.rng.shuffle(cls_idx)
            for i, idx in enumerate(cls_idx):
                fold_indices[i % self.k].append(idx)

        splits = []
        for i in range(self.k):
            test_idx  = np.array(fold_indices[i])
            train_idx = np.array([idx for j in range(self.k)
                                  if j != i
                                  for idx in fold_indices[j]])
            splits.append((train_idx, test_idx))
        return splits


sk_cv = StratifiedKFoldCV(k=5, random_state=42)
for i, (train_idx, test_idx) in enumerate(sk_cv.split(X, y)):
    classes, counts = np.unique(y[test_idx], return_counts=True)
    print(f"Fold {i+1}: Test-Klassenverteilung = {dict(zip(classes, counts))}")

Stufe 5

🚀 Cross-Validation mit sklearn

cross_val_score: Die schnellste Variante

🐍 Schritt 1 — Pipeline & einfache CV 
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.svm import SVC
from sklearn.datasets import load_breast_cancer
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline

X, y = load_breast_cancer(return_X_y=True)

# Pipeline: Scaling + Modell (wichtig für korrekte CV!)
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('svm',    SVC(kernel='rbf'))
])

cv = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)
scores = cross_val_score(pipe, X, y, cv=cv, scoring='accuracy')
print(f"Accuracy: {scores.mean():.4f} ± {scores.std():.4f}")
▶ Ausgabe
Accuracy: 0.9772 ± 0.0163

results = cross_validate(

🐍 Schritt 3 — Hyperparameter-Tuning mit GridSearchCV 
from sklearn.model_selection import GridSearchCV

param_grid = {
    'svm__C':      [0.1, 1.0, 10.0],
    'svm__gamma':  ['scale', 'auto', 0.001, 0.01],
}

grid_search = GridSearchCV(
    pipe,
    param_grid,
    cv=StratifiedKFold(n_splits=5, shuffle=True, random_state=42),
    scoring='accuracy',
    n_jobs=-1,
    refit=True
)
grid_search.fit(X, y)

print(f"Beste Parameter: {grid_search.best_params_}")
print(f"Beste CV Accuracy: {grid_search.best_score_:.4f}")
