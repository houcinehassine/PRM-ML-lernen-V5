🧭 PCA & Dimensionsreduktion

Hochdimensionale Daten auf die wichtigsten Achsen reduzieren: Kovarianzmatrix, Eigenvektoren, erklärte Varianz und Principal Component Analysis mit sklearn.

Stufe 1

🎯 Ziel & Kontext

Warum Dimensionen reduzieren?

Reale Datensätze haben oft viele Features — manche davon korreliert, redundant oder verrauscht. Principal Component Analysis (PCA) ist die Standardmethode, um solche Daten auf wenige, möglichst informative Achsen zu reduzieren — unüberwacht, also ganz ohne Labels y.

AnwendungBeispielNutzen
Visualisierungz.B. 4 Features → 2D-ScatterplotCluster/Muster mit dem Auge erkennen
Preprocessingvor KMeans, Classifier, Regressionweniger Rauschen, schnelleres Training
KompressionBilder, Sensordatenweniger Speicher, kaum Informationsverlust
Multikollinearitätstark korrelierte Features in der Regressionentfernt redundante Achsen
Kernidee von PCA: Finde neue, orthogonale Achsen ("Hauptkomponenten"), die die Varianz der Daten maximal erklären. Sortiere sie nach erklärter Varianz und behalte nur die ersten k — der Rest wird verworfen.
PCA ist unüberwacht — sie kennt die Zielvariable y nicht und optimiert rein nach Varianz. Eine Hauptkomponente mit viel Varianz ist nicht automatisch nützlich, um y vorherzusagen!
Stufe 2

🧠 Kovarianzmatrix, Eigenvektoren & erklärte Varianz

Kovarianzmatrix

Zuerst wird jedes Feature zentriert (Mittelwert abziehen) — bei unterschiedlichen Skalen zusätzlich standardisiert. Die Kovarianzmatrix Σ (d×d bei d Features) beschreibt, wie stark Features gemeinsam variieren:

Σ = (1 / (n−1)) · Xᶜᵀ · Xᶜ   (Xᶜ = zentrierte Daten)
Σᵢᵢ = Varianz von Feature i  ·  Σᵢⱼ = Kovarianz zwischen Feature i und j

Beispiel: 10 Punkte mit 2 korrelierten Features, Mittelwert ≈ (1.81, 1.91):

Σ ≈ [[0.6166, 0.6154],
    [0.6154, 0.7166]]

Die positiven Werte abseits der Diagonale zeigen: beide Features steigen meist gemeinsam — ein Hinweis, dass eine gemeinsame Achse beide gut zusammenfassen kann.

Eigenvektoren & Eigenwerte

Die Hauptkomponenten sind die Eigenvektoren v der Kovarianzmatrix. Die zugehörigen Eigenwerte λ geben an, wie viel Varianz entlang dieser Achse liegt:

Σ · v = λ · v

Für das Beispiel oben (absteigend nach λ sortiert):

λ₁ = 1.2840   v₁ ≈ (0.678, 0.735)   → PC1 (Hauptachse)
λ₂ = 0.0491   v₂ ≈ (−0.735, 0.678)   → PC2 (orthogonal zu PC1)

v₁ zeigt etwa in Richtung der Diagonale — entlang dieser Achse streuen die Punkte am stärksten. v₂ steht im rechten Winkel dazu und fängt nur noch den "Rest" der Streuung ein.

Erklärte Varianz & Scree-Plot

erklärte Varianz (Anteil)ᵢ = λᵢ / Σⱼ λⱼ

Hier: λ₁ / (λ₁+λ₂) = 1.284 / 1.333 ≈ 0.963 — PC1 allein erklärt 96.3 % der gesamten Varianz, PC2 nur 3.7 %. Im Scree-Plot trägt man die erklärte Varianz pro Komponente auf (absteigend sortiert) — analog zur Elbow-Methode (Thema 2) sucht man den "Ellbogen", ab dem zusätzliche Komponenten kaum noch etwas beitragen.

PCA reagiert empfindlich auf die Skalierung der Features! Ohne StandardScaler dominiert das Feature mit den größten Zahlenwerten künstlich die erste Hauptkomponente — nicht, weil es inhaltlich wichtiger ist, sondern nur wegen seiner Skala.
Stufe 3

⚙️ PCA-Algorithmus

1
Daten zentrieren (und meist standardisieren)

Mittelwert jeder Spalte abziehen — bei unterschiedlichen Skalen zusätzlich durch die Standardabweichung teilen (StandardScaler).

2
Kovarianzmatrix Σ berechnen

d×d-Matrix bei d Features.

3
Eigenwerte λᵢ und Eigenvektoren vᵢ von Σ bestimmen

Σ·v = λ·v — die Eigenvektoren stehen automatisch orthogonal zueinander.

4
Nach Eigenwert absteigend sortieren

Größter Eigenwert → PC1 (Hauptkomponente 1), zweitgrößter → PC2, usw.

5
k bestimmen (Scree-Plot oder Ziel-Varianz)

So viele Komponenten behalten, bis z.B. 90-95 % der Varianz erklärt sind.

6
Projizieren: X_neu = Xᶜ · Wᵀ

W enthält die ersten k Eigenvektoren als Zeilen — entspricht fit_transform().

7
Optional: Rekonstruieren

X_rekon = X_neu · W + Mittelwert — inverse_transform(). Differenz zu X = Informationsverlust.

Stufe 4

🛠️ PCA von Scratch (Eigenzerlegung)

Python · 1/2 — PCA-Fit: Kovarianzmatrix & Eigenzerlegung
import numpy as np

def pca_fit(X, n_components):
    mean = X.mean(axis=0)
    X_centered = X - mean

    # Kovarianzmatrix (Features x Features)
    cov = np.cov(X_centered, rowvar=False)

    # Eigenzerlegung -- Sigma ist symmetrisch -> eigh (aufsteigend sortiert)
    eigvals, eigvecs = np.linalg.eigh(cov)

    # absteigend sortieren: größter Eigenwert = PC1
    order = np.argsort(eigvals)[::-1]
    eigvals = eigvals[order]
    eigvecs = eigvecs[:, order]

    components = eigvecs[:, :n_components].T          # (n_components, n_features)
    explained_variance = eigvals[:n_components]
    explained_variance_ratio = explained_variance / eigvals.sum()

    return mean, components, explained_variance_ratio
Python · 2/2 — Transform, Inverse-Transform & Test
def pca_transform(X, mean, components):
    return (X - mean) @ components.T

def pca_inverse_transform(X_proj, mean, components):
    return X_proj @ components + mean


# Klassischer Datensatz: 10 Punkte, 2 stark korrelierte Features
X = np.array([[2.5,2.4],[0.5,0.7],[2.2,2.9],[1.9,2.2],[3.1,3.0],
               [2.3,2.7],[2.0,1.6],[1.0,1.1],[1.5,1.6],[1.1,0.9]])

mean, components, ratio = pca_fit(X, n_components=2)
print("Mittelwert:", mean)
print("Komponenten (Zeilen = PC1, PC2):\n", components)
print("Erklärte Varianz (Anteil):", ratio)

# Auf 1 Dimension reduzieren und wieder rekonstruieren
mean1, comp1, ratio1 = pca_fit(X, n_components=1)
X_proj = pca_transform(X, mean1, comp1)
X_rekon = pca_inverse_transform(X_proj, mean1, comp1)

mse = np.mean(np.sum((X - X_rekon)**2, axis=1))
print("\nProjektion auf PC1 (erste 4 Punkte):", X_proj[:4].ravel())
print("Rekonstruktionsfehler (MSE):", round(mse, 4))

Stufe 5

🚀 PCA mit sklearn

Python · PCA auf dem Iris-Datensatz (4D → 2D)
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import numpy as np

iris = load_iris()
X, y = iris.data, iris.target          # 150 Samples, 4 Features

X_scaled = StandardScaler().fit_transform(X)   # PCA braucht skalierte Daten!

# 1) Scree: erklärte Varianz aller Komponenten
pca_full = PCA().fit(X_scaled)
print("Erklärte Varianz pro Komponente:", pca_full.explained_variance_ratio_)
print("Kumulativ:                      ", np.cumsum(pca_full.explained_variance_ratio_))

# 2) Auf 2 Dimensionen reduzieren
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)
print(f"\nShape: {X.shape} -> {X_pca.shape}")
print("explained_variance_ratio_:", pca.explained_variance_ratio_)
print(f"Summe (PC1+PC2): {pca.explained_variance_ratio_.sum():.4f}")

# 3) components_: Beitrag jedes Original-Features zu PC1/PC2
print("\ncomponents_ (Zeilen=PCs, Spalten=Features):\n", pca.components_)

# 4) Rücktransformation -- wie viel Information geht verloren?
X_rekon = pca.inverse_transform(X_pca)
mse = np.mean((X_scaled - X_rekon)**2)
print(f"\nRekonstruktionsfehler (MSE): {mse:.4f}")

Interpretation: PC1 hat hohe positive Ladungen auf Sepal-Length, Petal-Length und Petal-Width — eine Art "Gesamtgröße"-Achse der Blüte. PC2 wird fast ausschließlich von Sepal-Width dominiert. Mit nur 2 von 4 Features erklärt PCA hier 95.8 % der Varianz — Iris lässt sich fast verlustfrei in 2D visualisieren oder z.B. vor KMeans als Preprocessing nutzen.
