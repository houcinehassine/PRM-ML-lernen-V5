🌊 DBSCAN

Density-Based Spatial Clustering: findet Cluster beliebiger Form, erkennt Ausreißer automatisch — und braucht kein k.

Stufe 1

🎯 Ziel & Kontext

Wo k-means versagt

k-means hat fundamentale Einschränkungen:

  • Setzt sphärische (runde) Cluster voraus
  • Erkennt keine Ausreißer — jeder Punkt wird einem Cluster zugewiesen
  • Braucht k als Input

DBSCAN löst alle drei Probleme: findet Cluster beliebiger Form, markiert Ausreißer als Rauschen (−1), bestimmt die Anzahl der Cluster automatisch.

Anwendungsbeispiele: Geographische Cluster (Einwohner-Dichte), Anomalie-Erkennung, biologische Zell-Cluster, nicht-konvexe Strukturen.
Stufe 2

🧠 Kernpunkte, Randpunkte, Rauschen

Zwei Parameter steuern DBSCAN

ParameterBedeutung
ε (eps)Maximaler Abstand für Nachbarschaft — Radius um einen Punkt
min_samplesMindestanzahl Punkte in ε-Nachbarschaft um Kernpunkt zu sein

Drei Typen von Punkten

🟢
Kernpunkt (Core)

Hat ≥ min_samples Nachbarn im ε-Radius. Bildet das Innere eines Clusters.

🟡
Randpunkt (Border)

Im ε-Radius eines Kernpunkts, aber selbst weniger als min_samples Nachbarn.

🔴
Rauschen (Noise)

Weder Kernpunkt noch in ε-Radius eines Kernpunkts. Label = −1 (Ausreißer).

ε und min_samples wählen

ParameterKleinGroß
εViele kleine Cluster, mehr NoiseWenige große Cluster, wenig Noise
min_samplesMehr Kernpunkte, weniger NoiseWeniger Kernpunkte, mehr Noise
Faustregel: min_samples ≥ Anzahl Features + 1, mindestens 3. ε via k-Distanz-Plot schätzen: sortiere Abstände zum k-nächsten Nachbarn — der Knick zeigt ein gutes ε.
Stufe 3

⚙️ DBSCAN-Algorithmus

1
Alle Punkte als "unbesucht" markieren
2
Für jeden unbesuchten Punkt p:

p als "besucht" markieren. ε-Nachbarschaft N(p) berechnen.

3
Wenn |N(p)| < min_samples: p = Rauschen (vorerst)

Kann später als Randpunkt adoptiert werden.

4
Wenn |N(p)| ≥ min_samples: p = Kernpunkt → neues Cluster starten

Alle Nachbarn zum Cluster hinzufügen. Für jeden neuen Kernpunkt in N(p): deren Nachbarn ebenfalls dazu (rekursiv/Warteschlange).

5
Wiederholen bis alle Punkte besucht
Zeitkomplexität: O(n log n) mit räumlichem Index (KD-Tree), O(n²) naiv.
Stufe 4

🛠️ Von Scratch: DBSCAN implementieren

Python · DBSCAN von Scratch
import numpy as np
from collections import deque

class DBSCAN:
    """DBSCAN von Scratch (naiv, O(n²))."""

    UNVISITED = -2
    NOISE     = -1

    def __init__(self, eps=0.5, min_samples=5):
        self.eps = eps
        self.min_samples = min_samples

    def _neighbors(self, X, i):
        """Alle Punkte im ε-Radius um X[i]."""
        dists = np.sqrt(np.sum((X - X[i])**2, axis=1))
        return np.where(dists <= self.eps)[0]

    def fit_predict(self, X):
        X = np.array(X)
        n = len(X)
        labels = np.full(n, self.UNVISITED)
        cluster_id = 0

        for i in range(n):
            if labels[i] != self.UNVISITED:
                continue

            neighbors = self._neighbors(X, i)

            if len(neighbors) < self.min_samples:
                labels[i] = self.NOISE
                continue

            # Neues Cluster starten
            labels[i] = cluster_id
            queue = deque(neighbors)

            while queue:
                j = queue.popleft()

                if labels[j] == self.NOISE:
                    labels[j] = cluster_id  # Randpunkt adoptieren

                if labels[j] != self.UNVISITED:
                    continue

                labels[j] = cluster_id
                j_neighbors = self._neighbors(X, j)
                if len(j_neighbors) >= self.min_samples:
                    queue.extend(j_neighbors)

            cluster_id += 1

        self.labels_ = labels
        self.n_clusters_ = cluster_id
        return labels

🚀 DBSCAN mit sklearn — ε automatisch schätzen

Python · DBSCAN sklearn mit eps-Schätzung
from sklearn.cluster import DBSCAN
from sklearn.neighbors import NearestNeighbors
from sklearn.datasets import make_moons, make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score
import numpy as np

# Datensatz mit Rauschen
X, _ = make_moons(n_samples=300, noise=0.08, random_state=42)
X = StandardScaler().fit_transform(X)

# eps schätzen: k-Distanz-Plot
# Für min_samples=5: 4-te nächste-Nachbar-Distanz sortieren
k = 5 - 1
nbrs = NearestNeighbors(n_neighbors=k).fit(X)
distances, _ = nbrs.kneighbors(X)
kth_distances = np.sort(distances[:, -1])[::-1]  # absteigend sortieren

# Der "Knick" ist das optimale eps
# Automatisch: zweite Ableitung
diffs2 = np.diff(np.diff(kth_distances))
eps_idx = np.argmax(np.abs(diffs2)) + 1
eps_estimate = kth_distances[eps_idx]
print(f"Geschätztes eps: {eps_estimate:.4f}")

# DBSCAN mit geschätztem eps
db = DBSCAN(eps=eps_estimate, min_samples=5)
labels = db.fit_predict(X)

n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
n_noise = np.sum(labels == -1)
print(f"Cluster: {n_clusters}")
print(f"Noise:   {n_noise} ({n_noise/len(X):.1%})")

if n_clusters > 1:
    # Silhouette nur auf Nicht-Noise-Punkten
    mask = labels != -1
    sil = silhouette_score(X[mask], labels[mask])
    print(f"Silhouette (ohne Noise): {sil:.4f}")

# k-means vs DBSCAN Vergleich
from sklearn.cluster import KMeans
km = KMeans(n_clusters=2, random_state=42).fit(X)
km_sil = silhouette_score(X, km.labels_)
print(f"\nk-means Silhouette: {km_sil:.4f}")
print(f"DBSCAN  Silhouette: {sil:.4f}  ← besser für Moons!")
