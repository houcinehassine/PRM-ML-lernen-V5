🔵 k-means Algorithmus

Wie teilt k-means Datenpunkte in k Gruppen auf — und was passiert intern bei jeder Iteration?

Stufe 1

🎯 Ziel & Kontext

Unsupervised Learning: keine Labels

k-means gehört zum Unsupervised Learning — es gibt keine vorgegebenen Labels. Das Ziel ist, ähnliche Datenpunkte in k Gruppen (Cluster) zusammenzufassen, ohne vorher zu wissen welche Gruppen existieren.

Anwendungsbeispiele:
• Kundensegmentierung (welche Kundentypen gibt es?)
• Bildkompression (k häufigste Farben)
• Anomalie-Erkennung (Punkte weit vom nächsten Zentroid)
• Vorstufe für Supervised Learning
Kernfrage: Wie findet man die k "natürlichsten" Gruppen — und wie wählt man k?
Stufe 2

🧠 Theorie: Zielfunktion und Konvergenz

Was k-means minimiert

k-means minimiert die Within-Cluster Sum of Squares (WCSS) — auch Inertia genannt:

WCSS = Σₖ Σᵢ∈Cₖ ||xᵢ − μₖ||²

wobei μₖ der Centroid (Mittelpunkt) von Cluster k ist. WCSS misst, wie "kompakt" die Cluster sind.

Eigenschaften

EigenschaftDetails
KonvergenzGarantiert — WCSS sinkt monoton. Aber: möglicherweise lokales Minimum!
EmpfindlichkeitGegen Initialisierung und Ausreißer. k-means++ hilft bei der Init.
ClusterformSetzt sphärische (kugelförmige) Cluster voraus.
SkalierungFeatures MÜSSEN skaliert werden — k-means ist Distanz-basiert.

k-means++ Initialisierung

Statt zufälliger Centroid-Wahl: erster Centroid zufällig, jeder weitere proportional zu seinem Abstand zum nächsten bestehenden Centroid. Verhindert das Zusammenfallen von Centroids. Standard in sklearn (init='k-means++').
Stufe 3

⚙️ Lloyd's Algorithmus — Schritt für Schritt

1
Initialisierung: k Centroids zufällig wählen (oder k-means++)

μ₁, μ₂, ..., μₖ als Startpunkte setzen.

2
Assignment-Schritt: Jeden Punkt dem nächsten Centroid zuweisen

cᵢ = argminₖ ||xᵢ − μₖ||²

3
Update-Schritt: Centroids als Mittelpunkt ihrer Cluster neu berechnen

μₖ = (1/|Cₖ|) · Σᵢ∈Cₖ xᵢ

4
Wiederholen bis Convergenz

Wenn keine Punkt-Zuweisungen sich mehr ändern → fertig. WCSS ist minimal.

Zeitkomplexität: O(n · k · t · d) — n Punkte, k Cluster, t Iterationen, d Dimensionen. Sehr skalierbar!
Stufe 4

🛠️ Von Scratch: k-means implementieren

🐍 1/2a — Klasse: KMeans (von Scratch)
import numpy as np

class KMeans:
    """k-means Clustering (Lloyd's Algorithmus) von Scratch."""

    def __init__(self, k=3, max_iter=300, tol=1e-4, random_state=42):
        self.k = k
        self.max_iter = max_iter
        self.tol = tol
        self.rng = np.random.default_rng(random_state)

    def _init_centroids(self, X):
        """k-means++ Initialisierung."""
        n = len(X)
        # Ersten Centroid zufällig wählen
        centroids = [X[self.rng.integers(n)]]
        for _ in range(self.k - 1):
            # Distanz zum nächsten bestehenden Centroid
            dists = np.array([
                min(np.sum((x - c)**2) for c in centroids)
                for x in X
            ])
            # Proportional zu Distanz² wählen
            probs = dists / dists.sum()
            idx = self.rng.choice(n, p=probs)
            centroids.append(X[idx])
        return np.array(centroids)

    def fit(self, X):
        X = np.array(X)
        self.centroids_ = self._init_centroids(X)
        self.inertia_history_ = []

        for iteration in range(self.max_iter):
            # Assignment-Schritt
            labels = self._assign(X)

            # Update-Schritt: neue Centroids
            new_centroids = np.array([
                X[labels == k].mean(axis=0) if np.sum(labels == k) > 0
                else self.centroids_[k]          # leeren Cluster behalten
                for k in range(self.k)
            ])

            # Inertia berechnen
            inertia = sum(
                np.sum((X[labels == k] - new_centroids[k])**2)
                for k in range(self.k)
            )
            self.inertia_history_.append(inertia)

            # Konvergenz prüfen
            shift = np.max(np.linalg.norm(new_centroids - self.centroids_, axis=1))
            self.centroids_ = new_centroids
            if shift < self.tol:
                break

        self.labels_ = self._assign(X)
        self.inertia_ = self.inertia_history_[-1]
        self.n_iter_ = iteration + 1
        return self

    def _assign(self, X):
        dists = np.array([
            np.sum((X - c)**2, axis=1)
            for c in self.centroids_
        ])  # Shape: (k, n)
        return np.argmin(dists, axis=0)

    def predict(self, X):
        return self._assign(np.array(X))

Test mit synthetischen Blob-Daten und Vergleich mit sklearns Implementierung:

🐍 1/2b — Test: KMeans von Scratch
from sklearn.datasets import make_blobs

X, y_true = make_blobs(
    n_samples=300,
    centers=4,
    cluster_std=0.8,
    random_state=42
)

km = KMeans(k=4)
km.fit(X)

print(f"Inertia:     {km.inertia_:.2f}")
print(f"Iterationen: {km.n_iter_}")
print(f"Cluster-Größen: {[np.sum(km.labels_ == i) for i in range(km.k)]}")

# Vergleich mit sklearn
from sklearn.cluster import KMeans as SKLearnKMeans
skm = SKLearnKMeans(n_clusters=4, random_state=42)
skm.fit(X)
print(f"\nsklearn Inertia: {skm.inertia_:.2f}")

# baut auf der vorherigen Zelle auf (X, km)

Stufe 5

🚀 k-means mit sklearn

🐍 Python — KMeans sklearn API
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score
import numpy as np

X, _ = make_blobs(
    n_samples=300,
    centers=4,
    cluster_std=0.8,
    random_state=42
)
X = StandardScaler().fit_transform(X)  # IMMER skalieren!

km = KMeans(
    n_clusters=4,
    init='k-means++',  # Standard, bessere Initialisierung
    n_init=10,         # 10 verschiedene Starts, bestes Ergebnis
    max_iter=300,
    random_state=42
)
km.fit(X)

print(f"Inertia (WCSS):    {km.inertia_:.4f}")
print(f"Iterationen:       {km.n_iter_}")
print(f"Centroids shape:   {km.cluster_centers_.shape}")

# Silhouette Score: Qualitätsmaß für Clustering (-1 bis 1, höher=besser)
score = silhouette_score(X, km.labels_)
print(f"Silhouette Score:  {score:.4f}")

# Neue Punkte zuweisen
new_points = np.array([[0.5, 0.5], [-1.0, 2.0]])
print(f"Neue Punkte → Cluster: {km.predict(new_points)}")

# Abstände zu Centroids
distances = km.transform(new_points)  # (n_points, k) Distanzmatrix
print(f"Distanzen zu Centroids:\n{distances.round(3)}")
