📐 Die Elbow-Methode

Das größte Problem bei k-means: Wie wählt man k? Die Elbow-Methode und der Silhouette Score geben Antworten.

Stufe 1

🎯 Ziel & Kontext

Das k-Problem

k-means braucht k als Input — aber wir wissen oft nicht vorher, wie viele Cluster in den Daten stecken. Mit k=1 gibt es null Fehler am Training; mit k=n ist jeder Punkt sein eigener Cluster (WCSS=0).

Ziel: Das "richtige" k finden — klein genug um sinnvoll zu sein, groß genug um die Struktur zu erfassen.

Zwei Methoden helfen: die Elbow-Methode (WCSS-Kurve) und der Silhouette Score (Kohäsion vs. Separation).

Stufe 2

🧠 Elbow-Methode und Silhouette Score

Elbow-Methode

Plotte WCSS gegen k = 1, 2, ..., K. Die Kurve sinkt zunächst stark, dann flacher. Der "Ellbogen" — der Punkt, an dem das Absinken abflacht — deutet auf das optimale k hin.

k=1: WCSS sehr hoch
k=2: WCSS stark gesunken ↓↓
k=3: noch gesunken ↓↓
k=4: wenig gesunken ↓ ← Elbow!
k=5: kaum gesunken →
k=6: kaum gesunken →

Silhouette Score

Für jeden Punkt i:

a(i) = mittlere Distanz zu Punkten im selben Cluster
b(i) = mittlere Distanz zum nächsten anderen Cluster
s(i) = (b(i) − a(i)) / max(a(i), b(i))
Silhouette = Mittelwert aller s(i) ∈ [-1, 1]
ScoreBedeutung
~ +1Punkt liegt tief im richtigen Cluster, weit weg von anderen
~ 0Punkt liegt auf der Grenze zwischen zwei Clustern
~ −1Punkt könnte zum falschen Cluster gehören

Stufe 4

🛠️ Von Scratch: Elbow & Silhouette

🐍 1/2a — Funktion: silhouette_score_scratch
import numpy as np

def silhouette_score_scratch(X, labels):
    """Silhouette Score von Scratch."""
    n = len(X)
    k_vals = np.unique(labels)
    scores = []

    for i in range(n):
        ci = labels[i]
        # a(i): mittlere Distanz zu gleicher Klasse
        same = X[labels == ci]
        if len(same) > 1:
            a = np.mean(np.sqrt(np.sum((same - X[i])**2, axis=1)))
        else:
            a = 0.0

        # b(i): minimale mittlere Distanz zu anderen Klassen
        b_vals = []
        for cj in k_vals:
            if cj == ci:
                continue
            other = X[labels == cj]
            b_vals.append(np.mean(np.sqrt(np.sum((other - X[i])**2, axis=1))))
        b = min(b_vals) if b_vals else 0.0

        if max(a, b) > 0:
            scores.append((b - a) / max(a, b))
        else:
            scores.append(0.0)

    return np.mean(scores)

Jetzt die Elbow-Methode: für mehrere k trainieren, WCSS und Silhouette Score sammeln und den Elbow automatisch finden:

🐍 2/2a — Funktion: find_optimal_k
def find_optimal_k(X, k_range=range(2, 11), n_init=10):
    """Elbow-Analyse und Silhouette-Scores."""
    wcss = []
    sil_scores = []

    for k in k_range:
        km = KMeans(n_clusters=k, n_init=n_init, random_state=42)
        km.fit(X)
        wcss.append(km.inertia_)
        sil = silhouette_score_scratch(X, km.labels_)
        sil_scores.append(sil)

    # Elbow automatisch finden (max. zweite Ableitung)
    wcss_arr = np.array(wcss)
    diffs = np.diff(wcss_arr)          # erste Ableitung
    diffs2 = np.diff(diffs)            # zweite Ableitung
    elbow_idx = np.argmax(diffs2) + 2  # +2 wegen zwei Diff-Ops und 0-Indexing

    print(f"{'k':>4} | {'WCSS':>12} | {'Silhouette':>12} | {'Elbow?':>8}")
    print("-" * 45)
    for i, k in enumerate(k_range):
        elbow_marker = "← ELBOW" if k == elbow_idx else ""
        print(f"{k:>4} | {wcss[i]:>12.2f} | {sil_scores[i]:>12.4f} | {elbow_marker}")

    best_k_sil = list(k_range)[np.argmax(sil_scores)]
    print(f"\nElbow bei k={elbow_idx}")
    print(f"Bester Silhouette Score bei k={best_k_sil}")
    return elbow_idx, best_k_sil

🚀 k-Auswahl mit sklearn

Python · Elbow & Silhouette mit sklearn
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, silhouette_samples
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
import numpy as np

X, _ = make_blobs(n_samples=400, centers=4, cluster_std=0.9, random_state=42)
X = StandardScaler().fit_transform(X)

# Systematische k-Analyse
results = {}
for k in range(2, 11):
    km = KMeans(n_clusters=k, n_init=10, random_state=42)
    labels = km.fit_predict(X)
    results[k] = {
        'inertia':   km.inertia_,
        'silhouette': silhouette_score(X, labels),
    }

print(f"{'k':>4} | {'Inertia':>10} | {'Silhouette':>12}")
print("-" * 32)
for k, vals in results.items():
    print(f"{k:>4} | {vals['inertia']:>10.2f} | {vals['silhouette']:>12.4f}")

# Optimales k wählen und finales Modell trainieren
best_k = max(results, key=lambda k: results[k]['silhouette'])
print(f"\nOptimales k (Silhouette): {best_k}")

km_final = KMeans(n_clusters=best_k, n_init=10, random_state=42)
km_final.fit(X)
print(f"Finales Modell: Inertia={km_final.inertia_:.2f}")

# Per-Sample Silhouette Scores
sample_silhouettes = silhouette_samples(X, km_final.labels_)
for k in range(best_k):
    ks = sample_silhouettes[km_final.labels_ == k]
    print(f"Cluster {k}: {len(ks)} Punkte, Silhouette Mean={ks.mean():.4f}")
